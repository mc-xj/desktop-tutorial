# 实验三：数组保存车辆版——代码解释

## 1. 本次结构

Car.java保存单辆车的属性、构造方法、getter/setter和租还状态；Rental.java保存一笔租赁的车与天数，并计算租金；Test.java使用Car[]保存3辆车，用Rental[]保存对应订单，负责输入与操作。运行入口为Test.main。Car和Rental的代码保持上一版写法。

## 2. 为什么使用Car[]

`Car[] cars = new Car[3];`创建长度为3的汽车引用数组。此时只有3个空格，每格默认为null，并不等于已经创建3辆车。所以还要分别为cars[0]、cars[1]、cars[2]赋值为new Car(...)。

| 用户看到的编号 | 数组下标 | 汽车 | 日租金 |
| --- | --- | --- | --- |
| 1 | 0 | 丰田 卡罗拉 白色 | 100元 |
| 2 | 1 | 本田 思域 黑色 | 80元 |
| 3 | 2 | 福特 福克斯 银色 | 90元 |

第一辆先使用无参构造，再用setter填写；后两辆使用有参构造。这样同时练习两种创建对象的方式。private字段不能由Test直接读写，需要使用getter/setter。

## 3. 怎样遍历显示

`for (int i = 0; i < cars.length; i++)`依次令i为0、1、2。`Car car = cars[i]`把这一格的汽车引用交给局部变量car，后面通过getter显示信息。这不是复制汽车，更不是创建新车。

`i + 1`只用于显示给用户的编号；真正读取数组时仍使用i。判断car.isRented()，为true显示“已租”，为false显示“可租”。

## 4. 两个数组怎样对应

`Rental[] orders = new Rental[cars.length]`创建同样长度的订单数组，初始各格都是null。固定使用同一个下标关联两组数据：cars[1]是2号车，orders[1]只能保存2号车的订单。

- 未出租：cars[i].isRented()为false，orders[i]为null。
- 出租后：cars[i].isRented()为true，orders[i]指向一笔订单。
- 还车后：恢复false，并把orders[i]重新设为null。

每辆车各有一个订单位置，所以租出1号车后，还能继续租出2号车，不会覆盖1号订单。同一辆车只允许一笔进行中的订单，不保存历史。

## 5. Scanner与readInt

readInt是自定义的静态方法，用来重复利用整数读取代码。hasNext检查是否还有输入（交互时可等待用户输入）；hasNextInt检查下一个内容能否读成整数；nextInt真正取出整数。若输入abc，next()丢弃它，再要求重新输入。

readInt在输入流结束时返回0：主菜单把0作为退出，选车和填天数时把0作为取消。输入流结束后，下一轮主菜单同样读到0，因此程序可以正常结束。readInt并不限制菜单和天数范围，范围由main中对应判断检查。

## 6. 按编号选车

用户输入number后，先检查1到cars.length的范围，然后才计算`int index = number - 1`。例如输入3，index=2，选中cars[2]。

不能在检查前访问cars[number-1]，否则输入99就可能越界。0会直接返回菜单，不会访问-1下标。

## 7. 租车的完整顺序

1. 主菜单输入1，表示租车。
2. 输入车辆编号，例如2，计算index=1。
3. 取cars[1]，检查是否已经出租，已租就拒绝。
4. 输入天数，例如3，校验1到365。
5. `orders[1] = new Rental(car, 3)`创建2号车订单。
6. `orders[1].rentCar()`改变同一辆本田车的状态。
7. `orders[1].getTotalPrice()`返回80×3=240，输出总租金。

构造Rental只是建立记录，rentCar才真正标记已租。汽车和订单通过对象引用关联。总价动态计算，不需要总价setter；正式收费系统还需要保存成交单价，本例不涉及。

## 8. 还车的完整顺序

主菜单输入2，再输入车辆编号。若orders[index]为null，提示没有需要归还的订单。否则先调用returnCar把对应车辆改为可租，再清空这一格订单引用。其他车辆与订单不变。

不要只写orders[index]=null，这不会自动把汽车状态改回false；也不要把整个orders数组重新创建，那会丢失其他车辆正在进行的订单。

## 9. 跟着输入（预期结果）

| 操作 | 依次输入 | 预期 |
| --- | --- | --- |
| 租1号车3天 | 1、1、3 | 总价300元，1号车已租 |
| 租2号车2天 | 1、2、2 | 总价160元，1号与2号都已租 |
| 重复租1号 | 1、1 | 拒绝重复出租，不再要求天数 |
| 归还1号 | 2、1 | 1号可租，2号仍已租 |
| 租3号车1天 | 1、3、1 | 总价90元 |

| 非法编号 | 1、99 | 提示编号无效 |

逗号表示先后输入，实际操作每次输入一个数字并按回车。上表是预期结果，不是用户运行截图。

## 10. 构造方法与封装复习

Car()和Car(String,String,String,int)同名、参数列表不同，是构造方法重载。Rental(Car)默认1天，Rental(Car,int)指定天数；菜单使用后者。构造方法没有返回类型，不能写void。

this.brand表示对象的字段，右边brand表示传入参数。getter返回属性值；setter负责修改，日租金与天数setter会拒绝非法数值。boolean属性采用isRented读取。可在IDEA的Generate菜单生成基本getter/setter，再手动补上校验。

## Car.java 完整源码

```java
// Car 表示一辆汽车，属性私有，通过方法访问。
public class Car {
    private String brand;       // 品牌
    private String model;       // 车型
    private String color;       // 颜色
    private int rentPrice;      // 每天租金，单位：元
    private boolean rented;     // 是否已经租出

    // 无参构造方法：先创建一辆车，再通过 setter 填资料。
    public Car() {
        this("未填写", "未填写", "未填写", 100);
    }

    // 有参构造方法：创建时一次填好资料。
    public Car(String brand, String model, String color, int rentPrice) {
        setBrand(brand);
        setModel(model);
        setColor(color);
        setRentPrice(rentPrice);
        rented = false;
    }

    public String getBrand() { return brand; }
    public void setBrand(String brand) { this.brand = brand; }
    public String getModel() { return model; }
    public void setModel(String model) { this.model = model; }
    public String getColor() { return color; }
    public void setColor(String color) { this.color = color; }
    public int getRentPrice() { return rentPrice; }
    public void setRentPrice(int rentPrice) {
        if (rentPrice <= 0) {
            throw new IllegalArgumentException("日租金必须大于0");
        }
        this.rentPrice = rentPrice;
    }
    // boolean 类型通常使用 is 开头的 getter。
    public boolean isRented() { return rented; }
    public void setRented(boolean rented) { this.rented = rented; }

    public void rent() { setRented(true); }
    public void returnCar() { setRented(false); }
}
```

## Rental.java 完整源码

```java
// Rental 表示一笔租车记录，关联汽车和租赁天数。
public class Rental {
    private Car car;
    private int rentalDays;

    // 构造方法重载：只提供汽车时，默认租1天。
    public Rental(Car car) {
        this(car, 1);
    }

    // 提供汽车和天数时，按指定天数创建记录。
    public Rental(Car car, int rentalDays) {
        setCar(car);
        setRentalDays(rentalDays);
    }

    public Car getCar() { return car; }
    public void setCar(Car car) {
        if (car == null) {
            throw new IllegalArgumentException("汽车不能为空");
        }
        this.car = car;
    }
    public int getRentalDays() { return rentalDays; }
    public void setRentalDays(int rentalDays) {
        if (rentalDays < 1 || rentalDays > 365) {
            throw new IllegalArgumentException("租赁天数应为1到365");
        }
        this.rentalDays = rentalDays;
    }

    // 总租金由日租金和天数决定，直接计算，不单独设置。
    public int getTotalPrice() {
        return car.getRentPrice() * rentalDays;
    }

    // 创建记录和真正租车分开，便于看清状态变化。
    public void rentCar() { car.rent(); }
    public void returnCar() { car.returnCar(); }
}
```

## Test.java 完整源码

```java
import java.util.Scanner;

// 用两个下标对应的数组，管理多辆汽车与各自的租赁记录。
public class Test {
    // 重复读取，直到得到整数；输入流结束时返回0。
    public static int readInt(Scanner input) {
        while (input.hasNext()) {
            if (input.hasNextInt()) {
                return input.nextInt();
            }
            System.out.println("请输入整数。");
            input.next(); // 丢弃错误输入，避免反复读取同一内容。
        }
        return 0;
    }

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        // 数组有3个格子，创建后格子内先是null，还没有汽车对象。
        Car[] cars = new Car[3];

        // 第一辆演示无参构造 + setter。
        cars[0] = new Car();
        cars[0].setBrand("丰田");
        cars[0].setModel("卡罗拉");
        cars[0].setColor("白色");
        cars[0].setRentPrice(100);
        // 其他两辆演示有参构造，三辆车都能实际租赁。
        cars[1] = new Car("本田", "思域", "黑色", 80);
        cars[2] = new Car("福特", "福克斯", "银色", 90);

        // orders[i] 保存cars[i]的订单，null表示这辆车没有进行中的订单。
        Rental[] orders = new Rental[cars.length];
        while (true) {
            System.out.println("\n【汽车租赁系统】");
            // 用户编号从1开始；数组下标从0开始。
            for (int i = 0; i < cars.length; i++) {
                Car car = cars[i];
                System.out.print((i + 1) + ". " + car.getBrand() + " "
                        + car.getModel() + " " + car.getColor()
                        + " 每天" + car.getRentPrice() + "元 ");
                if (car.isRented()) {
                    System.out.println("已租");
                } else {
                    System.out.println("可租");
                }
            }
            System.out.println("1 租车，2 还车，0 退出");
            int choice = readInt(input);
            if (choice == 0) break;
            if (choice != 1 && choice != 2) {
                System.out.println("请选择0、1或2。");
                continue;
            }

            System.out.println("请输入车辆编号（1到" + cars.length + "，0返回菜单）：");
            int number = readInt(input);
            if (number == 0) continue;
            // 先检查范围，再访问数组，避免数组下标越界。
            if (number < 1 || number > cars.length) {
                System.out.println("车辆编号无效。");
                continue;
            }
            int index = number - 1;
            Car car = cars[index];
            if (choice == 1) {
                if (car.isRented()) {
                    System.out.println("这辆车已经租出，请先还车。");
                    continue;
                }
                System.out.println("请输入租赁天数（1到365，0返回菜单）：");
                int days = readInt(input);
                if (days == 0) continue;
                if (days < 1 || days > 365) {
                    System.out.println("天数应在1到365之间。");
                    continue;
                }
                orders[index] = new Rental(car, days);
                orders[index].rentCar();
                System.out.println("租车成功：" + number + "号车，租赁"
                        + orders[index].getRentalDays() + "天");
                System.out.println("总租金：" + orders[index].getTotalPrice() + "元");
            } else {
                if (orders[index] == null) {
                    System.out.println("这辆车没有需要归还的订单。");
                } else {
                    orders[index].returnCar();
                    orders[index] = null;
                    System.out.println("还车成功：" + number + "号车。");
                }
            }
        }
        System.out.println("程序结束。");
    }
}
```
