## Circle.java：圆：π乘半径的平方

### 这个文件负责什么

radius 是半径，不是直径。Math.PI 是 Java 提供的圆周率近似值，计算结果为 double。

### 程序怎样执行

new Circle(2) → 半径2 → Math.PI×2×2 → 约12.566370614359172。

### 完整源码

```java
public class Circle extends Shape {
    private double radius;
    public Circle(double radius) {
        super("蓝色");
        this.radius = radius;
    }
    @Override
    public double getArea() { return Math.PI * radius * radius; }
}
```

## Shape.java：父类：规定图形都有颜色、都会算面积

### 这个文件负责什么

abstract 表示抽象类。它可以保存共有数据，但不允许直接 new Shape。getArea 只有声明，没有计算公式，具体子类必须实现。

### 程序怎样执行

创建子类 → 子类通过 super 调用 Shape 构造方法 → 保存颜色 → 调用 getColor 读取颜色；调用 getArea 时执行具体子类公式。

### 完整源码

```java
// 父类：把所有图形都有的内容放在一起。
public abstract class Shape {
    private String color;
    public Shape(String color) { this.color = color; }
    public String getColor() { return color; }
    // 每种图形的面积公式不同，所以这里不写具体公式。
    public abstract double getArea();
}
```

## ShapeManager.java：图形收纳盒：数组和多态

### 这个文件负责什么

shapes 有10个位置，初始每格为 null。add 找到第一个空格放对象；remove 找到指定对象后清空该格；display 遍历非空格并求和。

### 程序怎样执行

依次添加矩形、圆、三角形到下标0、1、2 → 显示时求20+12.566…+6 → 移除圆使下标1为null → 再次显示只求20+6。

### 完整源码

```java
public class ShapeManager {
    private Shape[] shapes = new Shape[10]; // 最多放 10 个图形。
    public void add(Shape shape) {
        if (shape == null) return;
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] == null) {
                shapes[i] = shape;
                return;
            }
        }
        System.out.println("已经放满了。");
    }
    public void remove(Shape shape) {
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] == shape) {
                shapes[i] = null;
                return;
            }
        }
    }
    public void display() {
        double total = 0;
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] != null) {
                Shape shape = shapes[i];
                System.out.println(shape.getColor() + "图形，面积：" + shape.getArea());
                total = total + shape.getArea();
            }
        }
        System.out.println("总面积：" + total);
    }
}
```

## Triangle.java：三角形：底乘高除以二

### 这个文件负责什么
