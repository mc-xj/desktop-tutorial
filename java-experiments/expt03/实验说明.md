# expt03：汽车租赁系统

## 目标与文件

完成“汽车租赁系统”实验。代码兼容 Java 8，无第三方依赖。

- `src/Car.java`
- `src/Rental.java`
- `src/RentalApp.java`

## 代码知识

Car 表示车辆，Rental 表示一次租赁，RentalApp 负责交互。private 封装状态，getter 提供只读访问。四参数和五参数构造方法展示重载，this(...) 复用初始化。Rental 持有 Car 对象引用，体现对象组合；租赁改变车辆状态，还车恢复状态。数组下标与用户编号相差 1。租金 = 天数 × 日租金，printf 的 %.2f 控制显示小数位。

## 实验步骤

1. 阅读 Car 属性、两个构造方法与 rent/returnCar 方法。
2. 阅读 Rental 中订单创建和总价计算，理解对象引用带来的状态变化。
3. 运行 RentalApp，输入 rent 1 3，查看总租金 300.00 元和已租状态。
4. 再次输入 rent 1 2，确认拒绝重复出租；输入 rent 2 0，确认拒绝非法天数。
5. 输入 return 1，确认还车成功，再输入 rent 1 1 检查重新出租，最后输入 0。

## IDEA 打开与运行

解压后在 IDEA 选择 File → Open，选择本目录 `expt03`。在 File → Project Structure → Project 设置已安装的 JDK（8 或更新版本），Language level 选择 8。`src` 已配置为 Sources Root；如未识别，右键 src → Mark Directory as → Sources Root。打开 `RentalApp.java`，点击 main 左侧绿色三角运行。也可选择预置的 `RentalApp` 运行配置。项目不包含机器专属 JDK 路径，需要首次选择本机 SDK。

## 命令行运行

在本实验目录执行（Windows、macOS、Linux 均可；先保证 JDK 在 PATH 中）：

```sh
mkdir out
javac -encoding UTF-8 -source 8 -target 8 -d out src/*.java
java -cp out RentalApp
```

`out` 已存在时跳过 mkdir；JDK 9+ 也可用 `javac --release 8 -encoding UTF-8 -d out src/*.java`。Windows 如通配符未展开，可逐一列出 src 中的 Java 文件。

## 预期结果与验收

租车 3 天为 300.00 元；重复出租被拒绝；还车后可再次出租。

## 与原文的差异及限制

补全原文缺少的 getBrand、构造重载和还车交互。数据只存在内存中，重启恢复初始状态；double 适合本题演示，实际财务系统应使用 BigDecimal。
