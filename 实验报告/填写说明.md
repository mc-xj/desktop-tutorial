# 实验报告填写说明

依据上传的《【信工】学生实验报告202609.doc》中的栏目，重新排版生成8份独立的.docx报告，便于Word/WPS打开和增补内容。不是将旧.doc逐像素复制；封面信息、评分、指导教师和正文栏目均保留。未从文件隐藏元数据推断学校或个人身份。

每份包含目的、原理、环境、耗材、实验步骤、测试计划、配套完整源码、截图空位、结果分析和结论填写区。预期结果标注为预期；实际结果、截图、个人总结请运行后填写。未生成或伪造运行截图。截图框可按实际截图尺寸扩展。

实验一增加Student类、创建学生对象、自我介绍以及int数组和for循环输出。修改后的可运行代码位于java-experiments/expt01/src。

本版仍基于高中生入门版项目：汽车只保留一辆，三角形用底和高，打卡使用LocalTime；并不补全原指导书的全部扩展要求。封面课程名为建议值，请按实际课程修改。

建议：先打开报告核对姓名等信息 → 在IDEA运行并截图 → 填实际结果 → 同步自己的代码修改 → 完善分析和结论 → 最后检查分页再打印。
