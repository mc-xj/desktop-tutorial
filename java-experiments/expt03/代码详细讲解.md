## Car.java：汽车模板：保存一辆车的信息

### 这个文件负责什么

brand 保存品牌，pricePerDay 保存整数日租金，rented 保存是否租出。构造方法用来给新车填写初始资料。

### 程序怎样执行

new Car("丰田", 100) → 构造方法填写字段 → rented=false。调用 rent 后变 true；调用 returnCar 后变 false。

### 完整源码

```java
// Car 类就像一张汽车信息卡。
public class Car {
    private String brand;
    private int pricePerDay;
    private boolean rented;

    public Car(String brand, int pricePerDay) {
        this.brand = brand;
        this.pricePerDay = pricePerDay;
        rented = false;
    }
    public String getBrand() { return brand; }
    public int getPricePerDay() { return pricePerDay; }
    public boolean isRented() { return rented; }
    public void rent() { rented = true; }
    public void returnCar() { rented = false; }
}
```

### 容易弄错的地方

this.brand 是对象字段，brand 是构造方法参数。private 只是限制直接访问，并不自动保证数据合理。这个简化类的 rent 不检查重复出租，检查放在 RentalApp 中。


## Rental.java：租赁记录：把车和天数放在一起

### 这个文件负责什么

car 保存那一辆汽车的引用，days 保存租赁天数。订单对象与主程序指向同一辆车，所以通过订单也能改变车辆状态。

### 程序怎样执行

new Rental(car, 3) → 保存车辆和天数 → car.rent() → getTotalPrice() 计算 100×3=300 → returnCar() 把车辆恢复可租。

### 完整源码

```java
// Rental 类记录一次租车的信息。
public class Rental {
    private Car car;
    private int days;
    public Rental(Car car, int days) {
        this.car = car;
        this.days = days;
        car.rent(); // 创建订单时，把汽车标记为已租。
    }
    public int getTotalPrice() {
        return car.getPricePerDay() * days;
    }
    public void returnCar() {
        car.returnCar();
    }
}
```

## RentalApp.java：主程序：把类串成租车流程

### 这个文件负责什么

car 是唯一一辆车；order 初始为 null，代表还没有订单。主菜单反复出现，选择 1 租车、2 还车、0 退出。

### 程序怎样执行

输入 1 和 3 → 建立订单 → 输出 300 元；再次输入 1 → 拒绝重复出租；输入 2 → 调用订单还车并清空 order；再输入 1 和 1 → 输出 100 元。

### 完整源码

```java
import java.util.Scanner;
public class RentalApp {
    public static void main(String[] args) {
        // 先只学习一辆车，避免同时处理太多信息。
        Car car = new Car("丰田", 100);
        Rental order = null;
        Scanner input = new Scanner(System.in);
        while (true) {
            System.out.println("汽车：" + car.getBrand() + "，每天 " + car.getPricePerDay() + " 元");
            System.out.println("是否已租：" + car.isRented());
            System.out.println("1 租车，2 还车，0 退出");
            if (!input.hasNext()) break;
            if (!input.hasNextInt()) {
                System.out.println("请输入数字。"); input.next(); continue;
            }
            int choice = input.nextInt();
            if (choice == 0) break;
            if (choice == 1) {
                if (car.isRented()) {
                    System.out.println("汽车已经租出去了。");
                    continue;
                }
                System.out.println("要租几天？请输入 1 到 365 的整数：");
                if (!input.hasNext()) break;
                if (!input.hasNextInt()) {
                    System.out.println("天数必须是整数。"); input.next(); continue;
                }
                int days = input.nextInt();
                if (days < 1 || days > 365) {
                    System.out.println("天数应在 1 到 365 之间。"); continue;
                }
                order = new Rental(car, days);
                System.out.println("租车成功，总租金：" + order.getTotalPrice() + " 元");
            } else if (choice == 2) {
                if (order == null) {
                    System.out.println("还没有租车。");
                } else {
                    order.returnCar(); order = null;
                    System.out.println("还车成功。");
                }
            } else {
                System.out.println("请选择 0、1 或 2。");
            }
        }
    }
}
```
