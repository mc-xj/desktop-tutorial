# 实验8：三个窗口卖十件挂件（高中生入门版）

## 先做什么

先运行看到结果，再读代码。一次只学本实验的几个知识点，不要求一次理解所有英文。建议按实验 1～8 的顺序学习；第 4、5、8 个实验可以分两次学习。

## 打开与运行（每个实验都一样）

1. 安装 JDK 8 或更新版本，以及 IntelliJ IDEA。
2. 完整解压，在 IDEA 选择 File → Open，打开本实验 expt08 文件夹。
3. 如果提示没有 JDK，在 File → Project Structure → Project SDK 选择本机 JDK。语言级别选 8。
4. 打开 src/Panda.java，点 main 左边的绿色三角，选择 Run。
5. 需要输入时，先点击下方 Run 窗口，再输入内容并按回车。

## 这次只学这些知识

1. 线程：可以把它想成三个同时工作的售货员，每个线程处理自己的工作。

2. static：三个售货员共用同一份库存，而不是每人都有 10 件。

3. start：开始工作；run：工作内容；join：主程序等待工作完成。

4. synchronized：像同一把仓库钥匙，一次只允许一人查库存并拿走商品。

5. 线程顺序不固定：可以某个平台卖得多，甚至全部卖完，不代表程序出错。

## 跟着做

1. 先运行 Panda，观察不同平台的售卖记录。

2. 数一数是不是恰好卖了 10 件，最后库存是不是 0。

3. 找到 synchronized，确认检查与扣减库存都在同一对大括号里。

4. 再运行几次，比较每个平台卖出的数量。

5. 理解：要保证总量正确，但不要求三个平台平均分配。

## 运行后应该看到

售出编号 1～10 各一次，最后显示售卖结束，剩余0件。

## 常见问题

找不到 JDK：先确认安装的是 JDK，不是只有 JRE。中文乱码：把项目编码设为 UTF-8。运行按钮不出现：右键 src，选择 Mark Directory as → Sources Root。更改代码后要重新运行，旧输出不会自动改变。
