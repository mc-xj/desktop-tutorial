# expt01：Java 编程环境与 HelloWorld

## 目标与文件

完成“Java 编程环境与 HelloWorld”实验。代码兼容 Java 8，无第三方依赖。

- `src/HelloWorld.java`

## 代码知识

`public class` 定义公共类，类名必须与文件名一致。`main(String[] args)` 是程序入口；`static` 允许 JVM 不创建对象直接调用。`System.out.println` 输出一行文本。javac 把源文件编译成 .class，java 运行字节码。

## 实验步骤

1. 安装 JDK 8 或更新版本，不能只安装 JRE。Windows 设置 JAVA_HOME 为 JDK 目录，把 %JAVA_HOME%\bin 加入 Path；macOS/Linux 将 $JAVA_HOME/bin 加入 PATH。
2. 重新打开终端，运行 java -version 和 javac -version，确认都可用。
3. 阅读 src/HelloWorld.java，核对类名、文件名和 main 方法。
4. 按通用说明在 IDEA 打开项目并运行 HelloWorld；也可执行下方命令。
5. 将输出文字改成自己的姓名，再编译运行，观察输出变化。

## IDEA 打开与运行

解压后在 IDEA 选择 File → Open，选择本目录 `expt01`。在 File → Project Structure → Project 设置已安装的 JDK（8 或更新版本），Language level 选择 8。`src` 已配置为 Sources Root；如未识别，右键 src → Mark Directory as → Sources Root。打开 `HelloWorld.java`，点击 main 左侧绿色三角运行。也可选择预置的 `HelloWorld` 运行配置。项目不包含机器专属 JDK 路径，需要首次选择本机 SDK。

## 命令行运行

在本实验目录执行（Windows、macOS、Linux 均可；先保证 JDK 在 PATH 中）：

```sh
mkdir out
javac -encoding UTF-8 -source 8 -target 8 -d out src/*.java
java -cp out HelloWorld
```

`out` 已存在时跳过 mkdir；JDK 9+ 也可用 `javac --release 8 -encoding UTF-8 -d out src/*.java`。Windows 如通配符未展开，可逐一列出 src 中的 Java 文件。

## 预期结果与验收

输出 Hello, World! 和 Java 环境配置成功！

## 与原文的差异及限制

原文把运行命令写成 java Hello；本项目类名为 HelloWorld，应运行 java -cp out HelloWorld。
