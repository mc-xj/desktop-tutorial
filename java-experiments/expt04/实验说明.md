# 实验四 智能图形设计师

1. 在 IDEA 中打开 expt04，选择 JDK 8 或更新版本。
2. 打开 src/ShapeApp.java，运行 main。
3. 核对矩形 1、圆形 1、三角形 1、圆形 2 的编号及总面积 88.83。删除圆形 1 和三角形后，总面积为 70.27，圆形 2 保留原编号。
4. 核对字符串引用比较为 false，内容比较为 true。
5. 查看 1、2、3 被拒绝后的提示，确认原三角形面积仍为 6。
6. 试着将非法示例换成 0、4、5，观察有限正数校验的提示。

每个文件的职责、完整代码及逐行解释见《代码详细讲解.md》。项目使用三边构造三角形。
