# expt05：美食烹饪大赛

## 目标与文件

完成“美食烹饪大赛”实验。代码兼容 Java 8，无第三方依赖。

- `src/People.java`
- `src/DoFood.java`
- `src/ZhangSan.java`
- `src/LiSi.java`
- `src/CookingApp.java`

## 代码知识

抽象 People 保存共同状态并声明 knife，不能直接实例化。DoFood 定义行为契约，implements 实现接口；类可以继承一个父类并实现多个接口。仅有一个抽象方法的函数式接口支持 Lambda，(name, kind) -> ... 是其实现。forEach 接收 Lambda；Map 累计票数。父类引用可指向不同子类，接口转换在本例中成立，因为两个选手都实现 DoFood。

## 实验步骤

1. 先看 People，再看 DoFood，区分共同状态与行为约定。
2. 查看 ZhangSan 和 LiSi 对两种方法的实现。
3. 运行 CookingApp，观察蒸菜、炒菜及主持人 Lambda 的输出。
4. 跟踪 votes.forEach 中每张选票如何累加到 counts。
5. 将选票改为李四较多或平票，重新运行，确认胜负由统计结果决定。

## IDEA 打开与运行

解压后在 IDEA 选择 File → Open，选择本目录 `expt05`。在 File → Project Structure → Project 设置已安装的 JDK（8 或更新版本），Language level 选择 8。`src` 已配置为 Sources Root；如未识别，右键 src → Mark Directory as → Sources Root。打开 `CookingApp.java`，点击 main 左侧绿色三角运行。也可选择预置的 `CookingApp` 运行配置。项目不包含机器专属 JDK 路径，需要首次选择本机 SDK。

## 命令行运行

在本实验目录执行（Windows、macOS、Linux 均可；先保证 JDK 在 PATH 中）：

```sh
mkdir out
javac -encoding UTF-8 -source 8 -target 8 -d out src/*.java
java -cp out CookingApp
```

`out` 已存在时跳过 mkdir；JDK 9+ 也可用 `javac --release 8 -encoding UTF-8 -d out src/*.java`。Windows 如通配符未展开，可逐一列出 src 中的 Java 文件。
