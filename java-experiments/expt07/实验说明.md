# 实验7：三个农业部门的费用统计（高中生入门版）

## 先做什么

先运行看到结果，再读代码。一次只学本实验的几个知识点，不要求一次理解所有英文。建议按实验 1～8 的顺序学习；第 4、5、8 个实验可以分两次学习。

## 打开与运行（每个实验都一样）

1. 安装 JDK 8 或更新版本，以及 IntelliJ IDEA。
2. 完整解压，在 IDEA 选择 File → Open，打开本实验 expt07 文件夹。
3. 如果提示没有 JDK，在 File → Project Structure → Project SDK 选择本机 JDK。语言级别选 8。
4. 打开 src/Agricultural.java，点 main 左边的绿色三角，选择 Run。
5. 需要输入时，先点击下方 Run 窗口，再输入内容并按回车。

## 这次只学这些知识

1. ArrayList：像可以增加格子的数组，add 用来放入报销金额。

2. Integer：集合里整数使用的类型名；先记住 ArrayList<Integer> 表示整数列表。

3. Iterator：像依次翻账本，hasNext 问“还有吗”，next 取下一笔。

4. Map：像通讯录，通过部门名称找到该部门总额；put 存，get 取。

5. 金额用“分”存：5020 分等于 50.20 元；显示时除以 100.0。

## 跟着做

1. 运行 Agricultural，先看三个部门和合计金额。

2. 找到 rice.add(5020)，理解这是 50.20 元。

3. 阅读 sum 方法，给 total 写出每次累加后的值。

4. 阅读 totals.put，观察部门名称怎样对应总金额。

5. 给水稻部门加一笔 rice.add(1000)，再运行核对。

## 运行后应该看到

原始数据：水稻 100.10 元，小麦 89.90 元，玉米 140.57 元，合计 330.57 元。

## 自己动手的小练习

追加 10 元后，水稻应为 110.10 元，合计为 340.57 元。

## 和原实验的区别

不用 BigDecimal，改用整数分计算。固定小额数据适合练习，不是完整的财务系统。

## 常见问题

找不到 JDK：先确认安装的是 JDK，不是只有 JRE。中文乱码：把项目编码设为 UTF-8。运行按钮不出现：右键 src，选择 Mark Directory as → Sources Root。更改代码后要重新运行，旧输出不会自动改变。
