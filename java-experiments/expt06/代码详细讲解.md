## AttendanceApp.java：按一天内的时刻判断迟到

### 这个文件负责什么

deadline 是09:00，now 默认取北京时间。命令行参数可替代 now，让同一段代码测试不同时间。isAfter 是严格晚于，所以09:00:00仍成功。

### 程序怎样执行

无参数 → 当前北京时间；参数08:59:59 → 成功；09:00:00 → 成功；09:00:01 → throw → 跳过成功输出 → catch显示迟到提示；abc → parse失败 → 另一个catch提示格式错误。

### 完整源码

```java
import java.time.LocalTime;
import java.time.ZoneId;
import java.time.format.DateTimeParseException;

public class AttendanceApp {
    public static void main(String[] args) {
        LocalTime deadline = LocalTime.of(9, 0, 0); // 早上 9 点。
        LocalTime now = LocalTime.now(ZoneId.of("Asia/Shanghai"));
        try {
            // 不填参数就使用当前北京时间；填参数可以练习不同情况。
            if (args.length > 0) now = LocalTime.parse(args[0]);
            System.out.println("打卡时间：" + now);
            if (now.isAfter(deadline)) {
                throw new MyException("超过早上 9 点，打卡失败！");
            }
            System.out.println("打卡成功！");
        } catch (MyException e) {
            System.out.println(e.getMessage());
        } catch (DateTimeParseException e) {
            System.out.println("时间格式错误，请填写类似 08:59:59 的时间。");
        }
    }
}
```

### 容易弄错的地方

Program arguments 与控制台输入不同，本程序不使用 Scanner。LocalTime 不保存日期；不支持节假日、跨天班次等考勤规则。参数应使用 ISO 时间格式，例如08:59:59；也支持08:59。


## MyException.java：自定义异常：给迟到情况起名字

### 这个文件负责什么

继承 RuntimeException，创建一种专用于打卡迟到的异常。构造方法把提示文字交给父类保存。

### 程序怎样执行

new MyException("迟到提示") → super(message) 保存消息 → throw 抛出 → catch 中 e.getMessage() 取出文字。

### 完整源码

```java
public class MyException extends RuntimeException {
    private static final long serialVersionUID = 1L;
    public MyException(String message) { super(message); }
}
```

### 逐行解释

| 行号 | 代码 | 解释 |
| --- | --- | --- |
| 1 | `public class MyException extends RuntimeException {` | 定义这个文件中的公共类。extends 指定父类。 |
| 2 | `private static final long serialVersionUID = 1L;` | 固定的序列化版本标识，可先记住写法；本实验不演示序列化，它不影响打卡比较。 |
| 3 | `public MyException(String message) { super(message); }` | 构造方法：创建 MyException 对象时执行，参数用于填写初始资料。super(...) 先调用父类构造方法。 |
| 4 | `}` | 结束当前代码块；对应前面某个左大括号。 |

### 容易弄错的地方

serialVersionUID 是序列化版本标识，属于进阶知识，和是否迟到无关；保留固定写法即可。RuntimeException 属于非受检异常，不强制在每个调用点声明或捕获。
