完成“智能图形设计师”实验。代码兼容 Java 8，无第三方依赖。

- `src/ShapeApp.java`

## 代码知识

Shape 封装颜色、填充和边框等共有属性，抽象 area 方法要求子类计算面积。extends 表示继承，@Override 表示重写。List<Shape> 可以存储不同子类；调用 getArea 时按对象实际类型执行面积公式，体现多态。矩形用宽×高，圆用 πr²，三角形用海伦公式。面积动态计算，修改尺寸后不会出现旧缓存值。

## 实验步骤

1. 阅读 Shape 的私有属性、getter/setter 和抽象方法。
2. 分别实现矩形、圆、三角形公式，检查正数和三角不等式校验。
3. 阅读 ShapeManager，通过父类类型统一添加、移除、遍历图形。
4. 运行 ShapeApp，查看三个图形面积和总面积。
5. 比较移除圆、修改矩形宽度后的总面积；尝试 new Triangle(1, 2, 3)，观察参数异常。

## IDEA 打开与运行

解压后在 IDEA 选择 File → Open，选择本目录 `expt04`。在 File → Project Structure → Project 设置已安装的 JDK（8 或更新版本），Language level 选择 8。`src` 已配置为 Sources Root；如未识别，右键 src → Mark Directory as → Sources Root。打开 `ShapeApp.java`，点击 main 左侧绿色三角运行。也可选择预置的 `ShapeApp` 运行配置。项目不包含机器专属 JDK 路径，需要首次选择本机 SDK。

## 命令行运行

在本实验目录执行（Windows、macOS、Linux 均可；先保证 JDK 在 PATH 中）：

```sh
mkdir out
javac -encoding UTF-8 -source 8 -target 8 -d out src/*.java
java -cp out ShapeApp
```

`out` 已存在时跳过 mkdir；JDK 9+ 也可用 `javac --release 8 -encoding UTF-8 -d out src/*.java`。Windows 如通配符未展开，可逐一列出 src 中的 Java 文件。

原文正文要求三边三角形，示例却使用底和高；此处按正文采用三边与海伦公式，并补全颜色等属性及移除/显示功能。
