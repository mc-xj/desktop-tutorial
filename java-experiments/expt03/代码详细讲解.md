## 三、先理解类之间的关系

Car 像汽车信息卡，记录“这是什么车、每天多少钱、是否已租”。Rental 像租车单，记录“租哪辆车、租几天”。Test 像操作员，负责问用户、检查输入、调用对象方法、展示结果。

```text
Test.main
  ├─ new Car() → setter 填入丰田、卡罗拉、白色、100
  ├─ new Car(本田, 思域, 黑色, 80) → 展示有参构造
  └─ new Rental(car, days) → 租赁记录引用同一辆丰田车
        ├─ getTotalPrice() → 日租金 × 天数
        ├─ rentCar() → car.rent() → rented=true
        └─ returnCar() → car.returnCar() → rented=false
```

## 四、Car.java 详细解释

### 1. 为什么属性要加 private

例如 `private String brand;` 是对象内部的品牌。Test 不能写 `car.brand = "丰田"`，而要调用 `car.setBrand("丰田")`。这样可以把检查放在方法里，例如日租金小于等于0时拒绝赋值。private 不等于数据自动安全，仍要自己写检查。

String 保存文字，int 保存整数，boolean 只有 true/false。本例 rented 为 true 表示已租，false 表示可租。它是每辆车自己的字段，没有写 static，所以不是所有车共享同一个状态。

### 2. getter 与 setter 怎样命名

`getBrand()` 返回品牌，`setBrand(String brand)` 修改品牌；属性名的首字母改为大写后接在 get/set 后面。boolean 常用 `isRented()` 读取。getter 有返回值，setter 这里返回 void。

`this.brand = brand;` 左边 this.brand 是对象字段，右边 brand 是方法参数。两个名字一样时，用 this 区分。IDEA 可以右键 → Generate（常见快捷键 Alt+Insert，依系统键位而异）→ Getter and Setter 自动生成；生成日租金setter后仍需手动增加合法性判断。

### 3. 两个构造方法为什么同名

构造方法名必须与类名相同，不能写返回类型，连 void 也不能写。`Car()` 没有参数，`Car(String,String,String,int)` 有四个参数；参数列表不同就是重载，不是继承或重写。

无参构造中的 `this("未填写", "未填写", "未填写", 100)` 调用本类另一个构造方法，必须放在构造方法第一条语句。它不是再创建一辆车，而是复用初始化过程。由于已经自己写了有参构造，若还想用 new Car()，就要明确提供无参构造。

### 4. rent 与 returnCar

`rent()` 调用 setRented(true)，`returnCar()` 调用 setRented(false)。它们描述汽车可以进行的动作。重复出租的检查在 Test 中，不在这两个方法内；setter 也不自动处理订单，因此练习时只通过菜单租还车。

## 五、Rental.java 详细解释

### 1. 租车单保存什么

`private Car car` 保存汽车对象的引用，不是品牌字符串，也不是复制一辆新车。`private int rentalDays` 保存天数。本例不单独保存总价，因为总价可以通过两个已有数据计算。

### 2. 构造方法重载

`new Rental(car)` 调用一个参数的构造方法，其内部 `this(car, 1)` 转到两个参数的构造方法，默认1天。`new Rental(car, 3)` 直接指定3天。交互程序使用后者，前者用于学习重载，可以在 Test 中自行尝试。

构造时先 setCar，再 setRentalDays，确保车不为 null、天数为1～365。创建租车单不会自动把车租走；必须调用 order.rentCar()，从而更清楚地观察“创建对象”和“改变状态”是两个动作。

### 3. 总价为何没有 setter

`return car.getRentPrice() * rentalDays;` 表示取日租金，再乘天数，然后把结果返回调用处。100×3=300。若以后通过 setter 改了天数，再调用此方法会按新天数计算。这里不保存成交时价格，正式系统通常还需要锁定订单单价，不能直接把本例当真实收费系统。

## 六、Test.java 按执行顺序解释

### 1. 导入与输入工具

`import java.util.Scanner;` 使后面能使用 Scanner 的简短类名。`new Scanner(System.in)` 创建从标准输入读取内容的工具。nextInt 才真正读取整数；hasNextInt 只检查下一个输入是否可读为整数。检查失败后调用 next() 取走错误内容，避免下轮读到同一个错误。

### 2. 两种创建汽车的写法

`Car car = new Car();` 创建对象，把引用保存在 car 变量。随后四次 setter 依次填写资料。`Car anotherCar = new Car("本田", "思域", "黑色", 80)` 创建另一辆车，一次填好四项。两辆车彼此独立；anotherCar 只用于展示构造方法。

### 3. 菜单与判断

`Rental order = null` 表示暂时没有进行中的订单。while(true) 反复展示菜单。输入0时 break 离开循环。输入1走租车分支，输入2走还车分支，其他数字提示重新选择。continue 表示跳过本轮，重新回到菜单，不会结束整个程序。

`if (!input.hasNext()) break;` 处理输入流结束，在手动键盘输入时可能等待输入。不是“没人立即打字就自动退出”。

### 4. 租车

先检查 car.isRented()；已出租则拒绝。再读取天数、验证范围。只有通过检查后，才创建 `new Rental(car, days)`，再调用 rentCar 将状态变为 true。最后读取订单天数和总价输出。Test 中先提示校验，类中的setter再校验一次，分别保护交互流程与直接调用类的情况。

### 5. 还车

order 为 null 时说明没有进行中的订单。否则调用 order.returnCar() 恢复同一辆车的 rented=false，再用 order=null 清空当前订单引用。null 不会主动调用还车，也不是手动销毁对象；所以两句都要有，顺序也要正确。

## 八、容易写错的地方

- 构造方法不能写 void，new 后面要跟类名和括号。
- getter 的 return 与 System.out.println 不同：前者把值交回程序，后者只打印。
- Setter不是属性名本身，应该调用 car.setColor("白色")，不能写 car.color。
- 不要把Car与Rental都写成一个公共类；三个公共类分别放在同名.java文件。
- 本例 setCar/setRentalDays 用于理解属性访问，不是完整订单编辑流程；正在租赁时随意换车可能使记录与状态不一致。

## 附：Car.java 完整代码

```java
// Car 表示一辆汽车，属性私有，通过方法访问。
public class Car {
    private String brand;       // 品牌
    private String model;       // 车型
    private String color;       // 颜色
    private int rentPrice;      // 每天租金，单位：元
    private boolean rented;     // 是否已经租出

    // 无参构造方法：先创建一辆车，再通过 setter 填资料。
    public Car() {
        this("未填写", "未填写", "未填写", 100);
    }

    // 有参构造方法：创建时一次填好资料。
    public Car(String brand, String model, String color, int rentPrice) {
        setBrand(brand);
        setModel(model);
        setColor(color);
        setRentPrice(rentPrice);
        rented = false;
    }

    public String getBrand() { return brand; }
    public void setBrand(String brand) { this.brand = brand; }
    public String getModel() { return model; }
    public void setModel(String model) { this.model = model; }
    public String getColor() { return color; }
    public void setColor(String color) { this.color = color; }
    public int getRentPrice() { return rentPrice; }
    public void setRentPrice(int rentPrice) {
        if (rentPrice <= 0) {
            throw new IllegalArgumentException("日租金必须大于0");
        }
        this.rentPrice = rentPrice;
    }
    // boolean 类型通常使用 is 开头的 getter。
    public boolean isRented() { return rented; }
    public void setRented(boolean rented) { this.rented = rented; }

    public void rent() { setRented(true); }
    public void returnCar() { setRented(false); }
}
```

## 附：Rental.java 完整代码

```java
// Rental 表示一笔租车记录，关联汽车和租赁天数。
public class Rental {
    private Car car;
    private int rentalDays;

    // 构造方法重载：只提供汽车时，默认租1天。
    public Rental(Car car) {
        this(car, 1);
    }

    // 提供汽车和天数时，按指定天数创建记录。
    public Rental(Car car, int rentalDays) {
        setCar(car);
        setRentalDays(rentalDays);
    }

    public Car getCar() { return car; }
    public void setCar(Car car) {
        if (car == null) {
            throw new IllegalArgumentException("汽车不能为空");
        }
        this.car = car;
    }
    public int getRentalDays() { return rentalDays; }
    public void setRentalDays(int rentalDays) {
        if (rentalDays < 1 || rentalDays > 365) {
            throw new IllegalArgumentException("租赁天数应为1到365");
        }
        this.rentalDays = rentalDays;
    }

    // 总租金由日租金和天数决定，直接计算，不单独设置。
    public int getTotalPrice() {
        return car.getRentPrice() * rentalDays;
    }

    // 创建记录和真正租车分开，便于看清状态变化。
    public void rentCar() { car.rent(); }
    public void returnCar() { car.returnCar(); }
}
```

## 附：Test.java 完整代码

```java
import java.util.Scanner;

// 测试类负责输入、创建对象、调用方法和输出结果。
public class Test {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        // 方式一：无参构造 + setter，先有对象，再填写属性。
        Car car = new Car();
        car.setBrand("丰田");
        car.setModel("卡罗拉");
        car.setColor("白色");
        car.setRentPrice(100);

        // 方式二：有参构造，创建时直接填写全部资料。
        Car anotherCar = new Car("本田", "思域", "黑色", 80);
        System.out.println("构造方法示例：" + anotherCar.getBrand()
                + " " + anotherCar.getModel() + "，每天"
                + anotherCar.getRentPrice() + "元（只展示，不参与本次租赁）");

        Rental order = null; // null 表示还没有进行中的订单。
        while (true) {
            System.out.println("\n【汽车租赁系统】");
            System.out.println("当前汽车：" + car.getBrand() + " "
                    + car.getModel() + " " + car.getColor());
            System.out.println("每天租金：" + car.getRentPrice() + "元");
            System.out.println("是否已租：" + car.isRented());
            System.out.println("1 租车，2 还车，0 退出");
            if (!input.hasNext()) break;
            if (!input.hasNextInt()) {
                System.out.println("请输入数字菜单。");
                input.next(); // 取走错误输入，下一轮才能读到新内容。
                continue;
            }
            int choice = input.nextInt();
            if (choice == 0) break;

            if (choice == 1) {
                if (car.isRented()) {
                    System.out.println("这辆车已经租出，请先还车。");
                    continue;
                }
                System.out.println("请输入租赁天数（1到365）：");
                if (!input.hasNext()) break;
                if (!input.hasNextInt()) {
                    System.out.println("天数必须是整数。");
                    input.next();
                    continue;
                }
                int days = input.nextInt();
                if (days < 1 || days > 365) {
                    System.out.println("天数应在1到365之间。");
                    continue;
                }
                order = new Rental(car, days);
                order.rentCar();
                System.out.println("租车成功，租赁" + order.getRentalDays() + "天");
                System.out.println("总租金：" + order.getTotalPrice() + "元");
            } else if (choice == 2) {
                if (order == null) {
                    System.out.println("当前没有需要归还的汽车。");
                } else {
                    order.returnCar();
                    order = null;
                    System.out.println("还车成功。");
                }
            } else {
                System.out.println("请选择0、1或2。");
            }
        }
        System.out.println("程序结束。");
    }
}
```
