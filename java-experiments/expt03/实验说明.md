# 实验三：汽车租赁系统（课堂板书版）

本版重点为：Car/Rental类、私有属性、getter/setter、无参/有参构造与重载、new对象、Scanner、Test.main。请先阅读《代码详细讲解.md》。

## 文件

- src/Car.java：汽车资料与租还状态。
- src/Rental.java：租赁天数、汽车引用、计算总价。
- src/Test.java：测试入口、键盘输入、菜单流程。

## 运行步骤

1. IDEA打开expt03，选择JDK 8或更新版本。
2. 运行Test.main。先输入1，再输入3，核对总价300元。
3. 再输入1，观察拒绝重复出租。输入2归还，再租1天核对100元。
4. 输入0退出。测试文字、0天、366天等错误输入。

## 命令行

```sh
mkdir out
javac -encoding UTF-8 -d out src/*.java
java -cp out Test
```

out已存在时跳过mkdir。入口已由RentalApp改为Test。

## 与上一版的区别

补全品牌、车型、颜色，演示两种汽车构造方式，增加规范getter/setter与Rental构造重载；总价通过方法计算；创建订单和真正租出汽车分开。仍使用一辆车进行交互，另一辆车只演示构造方法。
