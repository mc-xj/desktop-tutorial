# 实验1：Java 环境与第一行输出（高中生入门版）

## 先做什么

先运行看到结果，再读代码。一次只学本实验的几个知识点，不要求一次理解所有英文。建议按实验 1～8 的顺序学习；第 4、5、8 个实验可以分两次学习。

## 打开与运行（每个实验都一样）

1. 安装 JDK 8 或更新版本，以及 IntelliJ IDEA。
2. 完整解压，在 IDEA 选择 File → Open，打开本实验 expt01 文件夹。
3. 如果提示没有 JDK，在 File → Project Structure → Project SDK 选择本机 JDK。语言级别选 8。
4. 打开 src/HelloWorld.java，点 main 左边的绿色三角，选择 Run。
5. 需要输入时，先点击下方 Run 窗口，再输入内容并按回车。

## 这次只学这些知识

1. 类：可以先把它理解为存放代码的盒子。HelloWorld 是这个盒子的名字。

2. main：程序的起点，初学时记住固定写法，不需要一次理解所有单词。

3. println：在屏幕上打印文字并换行。文字必须放在英文双引号里。

4. 分号：一条语句结束时通常要加英文分号。

## 跟着做

1. 打开 HelloWorld.java，找到 main 方法。

2. 点击 main 左边绿色三角，选择 Run。

3. 观察屏幕上的两行文字。

4. 把第二行的文字改成自己的姓名，再次运行。

看到 Hello, World! 和中文自我介绍。

与原文一致。注意运行的类名是 HelloWorld，不是 Hello。

## 选学：命令行

在本实验目录执行。已有 out 文件夹时跳过第一行：

```sh
mkdir out
javac -encoding UTF-8 -d out src/*.java
java -cp out HelloWorld
```

## 常见问题

找不到 JDK：先确认安装的是 JDK，不是只有 JRE。中文乱码：把项目编码设为 UTF-8。运行按钮不出现：右键 src，选择 Mark Directory as → Sources Root。更改代码后要重新运行，旧输出不会自动改变。


## 补充任务：实现一个类和数组 for 输出

1. 打开 Student.java：name 和 age 是学生属性，构造方法接收姓名和年龄，introduce 方法输出自我介绍。
2. 打开 HelloWorld.java：new Student("小明", 16) 创建学生对象，再调用 student.introduce()。
3. int[] scores = {85, 90, 95} 创建成绩数组；数组下标为 0、1、2。
4. for (int i = 0; i < scores.length; i++) 按顺序访问每个元素。i 从 0 开始，i++ 每次加 1，i 小于数组长度时继续。
5. 运行 HelloWorld，检查是否输出小明的自我介绍及 85、90、95 三次成绩。
6. 改成自己的姓名和年龄，再向数组添加第四个成绩，重新运行，确认循环自动输出四条成绩。

注意：界面显示的“第1次”用 i+1，但读取数组必须用 scores[i]，不能改成 scores[i+1]。
