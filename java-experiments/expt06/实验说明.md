# expt06：打卡异常提醒

## 目标与文件

完成“打卡异常提醒”实验。代码兼容 Java 8，无第三方依赖。

- `src/MyException.java`
- `src/AttendanceApp.java`

## 代码知识

MyException 继承 RuntimeException，是自定义非受检异常。throw 抛出异常，try/catch 捕获并提示。SimpleDateFormat 将 Date 与字符串相互转换；setLenient(false) 拒绝不存在的日期。after 比较两个时间点。截止时间必须使用打卡当天的日期，而不能把“09:00:00”解析到 1970 年再与今天比较。显式 Asia/Shanghai 时区避免运行机器默认时区不同。

## 实验步骤

1. 阅读 MyException 构造方法，理解 super(message) 如何保存错误说明。
2. 阅读 check 方法，确认只有严格晚于 09:00:00 才抛出异常。
3. 直接运行 AttendanceApp，验证当前北京时间的打卡结果。
4. 在 IDEA Run → Edit Configurations 的 Program arguments 填入带双引号的 "2026-11-05 08:59:59"，运行应成功。
5. 分别测试 "2026-11-05 09:00:00"、"2026-11-05 09:00:01" 和 "2026-02-30 09:00:00"，检查边界和非法日期。

## IDEA 打开与运行

解压后在 IDEA 选择 File → Open，选择本目录 `expt06`。在 File → Project Structure → Project 设置已安装的 JDK（8 或更新版本），Language level 选择 8。`src` 已配置为 Sources Root；如未识别，右键 src → Mark Directory as → Sources Root。打开 `AttendanceApp.java`，点击 main 左侧绿色三角运行。也可选择预置的 `AttendanceApp` 运行配置。项目不包含机器专属 JDK 路径，需要首次选择本机 SDK。

## 命令行运行

在本实验目录执行（Windows、macOS、Linux 均可；先保证 JDK 在 PATH 中）：

```sh
mkdir out
javac -encoding UTF-8 -source 8 -target 8 -d out src/*.java
java -cp out AttendanceApp
```

`out` 已存在时跳过 mkdir；JDK 9+ 也可用 `javac --release 8 -encoding UTF-8 -d out src/*.java`。Windows 如通配符未展开，可逐一列出 src 中的 Java 文件。

## 预期结果与验收

08:59:59 和 09:00:00 打卡成功；09:00:01 提示超过早 9 点；非法日期提示输入错误。
