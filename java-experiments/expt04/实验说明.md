# 实验4：图形面积小助手（高中生入门版）

## 先做什么

先运行看到结果，再读代码。一次只学本实验的几个知识点，不要求一次理解所有英文。建议按实验 1～8 的顺序学习；第 4、5、8 个实验可以分两次学习。

## 打开与运行（每个实验都一样）

1. 安装 JDK 8 或更新版本，以及 IntelliJ IDEA。
2. 完整解压，在 IDEA 选择 File → Open，打开本实验 expt04 文件夹。
3. 如果提示没有 JDK，在 File → Project Structure → Project SDK 选择本机 JDK。语言级别选 8。
4. 打开 src/ShapeApp.java，点 main 左边的绿色三角，选择 Run。
5. 需要输入时，先点击下方 Run 窗口，再输入内容并按回车。

## 这次只学这些知识

1. 继承：Rectangle、Circle、Triangle 都是一种 Shape，用 extends 表示。

2. 抽象方法：父类只说“要会算面积”，具体公式由子类实现。

3. 多态：同样调用 getArea()，矩形算长乘宽，圆算圆面积。

4. null：格子里还没有放对象；管理器用数组保存最多 10 个图形。

## 跟着做

1. 先运行 ShapeApp，看添加图形和移除圆形的结果。

2. 阅读 Rectangle.getArea()，用 4×5 验算矩形面积。

3. 阅读 Triangle.getArea()，用 3×4÷2 验算三角形面积。

4. 最后阅读 Shape 和 ShapeManager，观察父类如何统一管理子类。

5. 修改矩形的宽和高，再次运行并手算核对。

## 运行后应该看到

初始总面积约 38.57；移除圆形后为 26.0。圆面积可能显示较多小数。

## 自己动手的小练习

把矩形改成宽 6、高 5，移除圆后的总面积应该是多少？

## 和原实验的区别

三角形采用底×高÷2，省去海伦公式；只保留颜色，不包含填充、边框和尺寸修改功能。演示尺寸应为正数。

## 选学：命令行

在本实验目录执行。已有 out 文件夹时跳过第一行：

```sh
mkdir out
javac -encoding UTF-8 -d out src/*.java
java -cp out ShapeApp
```

## 常见问题

找不到 JDK：先确认安装的是 JDK，不是只有 JRE。中文乱码：把项目编码设为 UTF-8。运行按钮不出现：右键 src，选择 Mark Directory as → Sources Root。更改代码后要重新运行，旧输出不会自动改变。
