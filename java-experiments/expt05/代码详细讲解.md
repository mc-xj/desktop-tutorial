## CookingApp.java：比赛入口：展示菜品并数票

### 这个文件负责什么

先让两位选手展示，再遍历 votes。zhangVotes 和 liVotes 分别累加，比较后输出胜负。最后两行用 Lambda 演示函数式接口，可后学。

### 程序怎样执行

原始5票：张三、李四、张三、李四、张三；计数依次为(1,0)、(1,1)、(2,1)、(2,2)、(3,2)，因此张三胜。

### 完整源码

```java
public class CookingApp {
    public static void main(String[] args) {
        ZhangSan zhang = new ZhangSan();
        LiSi li = new LiSi();
        System.out.println("比赛开始！");
        zhang.makeFood(zhang.getName(), zhang.getKind());
        zhang.knife();
        li.makeFood(li.getName(), li.getKind());
        li.knife();
        String[] votes = {"张三", "李四", "张三", "李四", "张三"};
        int zhangVotes = 0;
        int liVotes = 0;
        for (int i = 0; i < votes.length; i++) {
            if (votes[i].equals("张三")) {
                zhangVotes++;
            } else if (votes[i].equals("李四")) {
                liVotes++;
            }
        }
        System.out.println("张三：" + zhangVotes + "票");
        System.out.println("李四：" + liVotes + "票");
        if (zhangVotes > liVotes) {
            System.out.println("张三胜！");
        } else if (zhangVotes < liVotes) {
            System.out.println("李四胜！");
        } else {
            System.out.println("平局！");
        }
        // 选学：Lambda 是接口实现的一种简短写法，先会运行即可。
        DoFood host = (name, kind) -> System.out.println(name + "宣布：" + kind);
        host.makeFood("主持人", "比赛结束");
    }
}
```

### 容易弄错的地方

equals 比较字符串内容；不要用 == 判断选票姓名。未知姓名在这个入门版中不会计入任何选手。Lambda 的 name、kind 是参数；这里只使用传入的文字输出主持信息，不会创建 People 选手。


## DoFood.java：接口：约定怎样展示做菜

### 这个文件负责什么

接口声明 makeFood 方法，要求接收姓名和菜品两个字符串。这里不保存选手资料。接口方法默认是 public abstract，不需要把这两个词全部写出来。

### 程序怎样执行

ZhangSan、LiSi 使用 implements 遵守约定 → 分别提供 makeFood 方法 → 入口调用时打印选手和菜品。

### 完整源码

```java
// 接口像一个约定：实现它的类必须会做菜。
public interface DoFood {
    void makeFood(String name, String kind);
}
```

### 逐行解释

| 行号 | 代码 | 解释 |
| --- | --- | --- |
| 1 | `// 接口像一个约定：实现它的类必须会做菜。` | 中文注释：接口像一个约定：实现它的类必须会做菜。。这行不参与运行。 |
| 2 | `public interface DoFood {` | 定义公共接口。接口说明需要提供哪些能力，具体执行过程交给实现类。 |
| 3 | `void makeFood(String name, String kind);` | 接口方法声明：接收姓名 name 和菜品 kind 两个字符串，不返回结果；实现类必须提供方法体。 |

## LiSi.java：李四：同样的结构，不同的行为

### 这个文件负责什么

结构与张三一致，姓名、菜品、烹饪方式分别是李四、回锅肉、炒。通过相似结构理解同一接口可以有不同实现。

## People.java：选手模板：共同信息和抽象动作

### 这个文件负责什么

name 是姓名，kind 是拿手菜。抽象 knife 方法在本题代码中表示烹饪方式，方法名沿用原实验，并不是一定表示切菜。

### 程序怎样执行

子类构造时调用 super → 父类保存姓名和菜品 → getter 提供读取 → knife 的具体内容由子类提供。

### 完整源码

```java
// 抽象类不能直接 new，它是给具体选手使用的模板。
public abstract class People {
    private String name;
    private String kind;
    public People(String name, String kind) {
        this.name = name;
        this.kind = kind;
    }
    public String getName() { return name; }
    public String getKind() { return kind; }
    public abstract void knife();
}
```
