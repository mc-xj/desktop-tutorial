# 实验五 美食烹饪大赛（课堂板书版）

## 实验内容
People 抽象类保存私有姓名、拿手菜，提供无参/有参构造、getter/setter 和抽象方法 knife。ZhangSan 与 LiSi 继承 People 并实现 DoFood。Test 展示菜品、用 List 保存选票、用 Lambda 遍历及 Stream 计票，三元表达式输出结果。

## 运行步骤
1. IDEA 打开 expt05，设置 JDK 8 或更新版本。
2. 运行 src/Test.java，观察两位选手的不同烹饪方式与默认选票。
3. 核对张三3票、李四2票、张三胜。
4. 在 Run → Edit Configurations 的 Program arguments 输入“李四 李四 张三”，验证李四胜。
5. 输入“张三 李四”验证平局，输入“王五”验证无效票提示。

参数中的引号仅作说明，实际只填姓名与空格。默认固定5票与提要一致，参数是便于验证的扩展。
详细解释含每个文件的源码及逐行三列表。原实验报告中的旧版代码可在需要时另行同步。

## 命令行
在本目录创建 out，再运行 javac -encoding UTF-8 -d out src/*.java，然后执行 java -cp out Test。
