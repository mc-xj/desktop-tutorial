# 实验6：早上 9 点打卡（高中生入门版）

## 先做什么

先运行看到结果，再读代码。一次只学本实验的几个知识点，不要求一次理解所有英文。建议按实验 1～8 的顺序学习；第 4、5、8 个实验可以分两次学习。

## 打开与运行（每个实验都一样）

1. 安装 JDK 8 或更新版本，以及 IntelliJ IDEA。
2. 完整解压，在 IDEA 选择 File → Open，打开本实验 expt06 文件夹。
3. 如果提示没有 JDK，在 File → Project Structure → Project SDK 选择本机 JDK。语言级别选 8。
4. 打开 src/AttendanceApp.java，点 main 左边的绿色三角，选择 Run。
5. 需要输入时，先点击下方 Run 窗口，再输入内容并按回车。

## 这次只学这些知识

1. LocalTime：表示一天中的时间，例如 08:59:59，不需要处理年月日。

2. isAfter：判断一个时间是否比另一个时间晚。

3. 异常：程序遇到特殊情况时发出的信号。throw 发出信号，catch 接住并显示提示。

4. MyException：我们自己命名的一种异常，用来表示打卡迟到。

## 跟着做

1. 阅读 main，找到截止时间 LocalTime.of(9, 0, 0)。

2. 直接运行，程序使用当前北京时间判断打卡。

3. 在 IDEA 的 Run → Edit Configurations → Program arguments 填入 08:59:59，再运行。

4. 把参数分别改为 09:00:00 和 09:00:01，观察变化。

5. 填入 abc，检查程序是否提示时间格式错误。

## 运行后应该看到

08:59:59 和 09:00:00 成功，09:00:01 失败。

## 自己动手的小练习

把截止时间改为 08:30:00，测试 08:29:59 和 08:30:01。

## 和原实验的区别

使用 Java 8 的 LocalTime 代替原文 SimpleDateFormat，避免混淆日期和时刻；这是学习简化版，若老师强制要求旧日期类需另行补充。

## 选学：命令行

在本实验目录执行。已有 out 文件夹时跳过第一行：

```sh
mkdir out
javac -encoding UTF-8 -d out src/*.java
java -cp out AttendanceApp
```

## 常见问题

找不到 JDK：先确认安装的是 JDK，不是只有 JRE。中文乱码：把项目编码设为 UTF-8。运行按钮不出现：右键 src，选择 Mark Directory as → Sources Root。更改代码后要重新运行，旧输出不会自动改变。
