# 实验5：美食烹饪大赛（高中生入门版）

## 先做什么

先运行看到结果，再读代码。一次只学本实验的几个知识点，不要求一次理解所有英文。建议按实验 1～8 的顺序学习；第 4、5、8 个实验可以分两次学习。

## 打开与运行（每个实验都一样）

1. 安装 JDK 8 或更新版本，以及 IntelliJ IDEA。
2. 完整解压，在 IDEA 选择 File → Open，打开本实验 expt05 文件夹。
3. 如果提示没有 JDK，在 File → Project Structure → Project SDK 选择本机 JDK。语言级别选 8。
4. 打开 src/CookingApp.java，点 main 左边的绿色三角，选择 Run。
5. 需要输入时，先点击下方 Run 窗口，再输入内容并按回车。

## 这次只学这些知识

1. 抽象类：People 保存选手共有的姓名、拿手菜，并要求选手实现做菜方式。

2. 接口：DoFood 是“会做菜”的约定，implements 表示遵守约定。

3. 重写：@Override 提醒我们，这个方法是在实现父类或接口的要求。

4. 计数：每读到一张选票，就让对应票数加 1，再用 if 比较。

5. 选学 Lambda：箭头 -> 可以简写接口实现。第一次学可先跳过最后两行。

## 跟着做

1. 运行 CookingApp，看看张三和李四各做了什么菜。

2. 阅读 ZhangSan 和 LiSi，找出蒸菜、炒菜的不同写法。

3. 找到 votes 数组，手动数一遍两个人的票。

4. 阅读 for 循环，观察每张票怎样变成计数。

5. 把一张张三票改成李四票，再次运行，看看结果是否改变。

## 运行后应该看到

原始选票张三 3 票、李四 2 票，张三胜；改变选票会改变胜负。

## 自己动手的小练习

把选票改为“张三、李四”，让程序输出平局。

## 和原实验的区别

用数组和普通循环替代集合与流操作，Lambda 只作为选学；选票仍为固定演示数据。

## 选学：命令行

在本实验目录执行。已有 out 文件夹时跳过第一行：

```sh
mkdir out
javac -encoding UTF-8 -d out src/*.java
java -cp out CookingApp
```

## 常见问题

找不到 JDK：先确认安装的是 JDK，不是只有 JRE。中文乱码：把项目编码设为 UTF-8。运行按钮不出现：右键 src，选择 Mark Directory as → Sources Root。更改代码后要重新运行，旧输出不会自动改变。
