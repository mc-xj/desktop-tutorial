# Java 代码详细解释：高中生入门版

本讲解对应当前 expt01～expt08 源码。建议打开源文件，边看代码边读解释；行号与本版本一致。代码没有修改，本材料只增加解释。

## 先认识几个符号

- `;`：通常表示一条语句结束。括号 `()` 放方法的参数或判断条件，大括号 `{}` 划出一块代码的范围。
- `=`：把右边的值保存到左边；`==`：判断是否相等。`!` 表示取反，`&&` 要求两边都成立，`||` 要求至少一边成立。
- `int`：整数；`double`：小数；`boolean`：true/false；`String`：文字。`String` 是类，不是基本数据类型。
- `public`：允许其他类访问；`private`：只允许本类直接访问；`static`：属于类；`final`：赋值后不能重新指向别的值或对象。
- `new`：创建对象。变量保存对象的引用，可以理解为找到对象的“地址线索”，并不等于复制整个对象。
- `void`：方法不返回结果；`return 值`：把结果交给调用者；单独的 `return`：立即结束这个方法。
- `main`：JVM 启动普通控制台程序时寻找的入口。`String[] args` 接收运行参数，并不是键盘输入；键盘输入在本项目中通过 Scanner 读取。
- `break`：结束所在的最近一层循环；`continue`：结束本轮循环，准备下一轮；两者都不是“关闭所有程序”的通用命令。
- `//` 后是注释，给人看，不会被执行。IDEA 行号、中文讲解和代码中的标点不能混在一起粘贴进源码。

## 先弄清三个不同动作

1. 编写：把代码保存到 .java 文件。
2. 编译：javac 检查语法和类型并生成 .class 文件。
3. 运行：java/JVM 执行字节码，从 main 开始。某个辅助类没有 main 很正常，它会被入口类使用。

## WerewolfGame.java：用数组模拟回合游戏

### 这个文件负责什么

roles[i] 是第 i 号玩家的身份，alive[i] 是同一玩家是否存活。两组数组必须一一对应。night 决定当前是夜间攻击还是白天投票。

### 程序怎样执行

初始 2 狼 5 民。输入 2：平民变 4，进入白天；输入 0：狼人变 1，进入夜晚；输入 3：平民变 3；输入 1：狼人变 0，下一轮统计后宣布平民胜。每轮重新统计，不沿用旧人数。

### 完整源码

```java
import java.util.Scanner;

// 这是公开身份的练习小游戏，用来学习数组、循环和判断。
public class WerewolfGame {
    public static void main(String[] args) {
        // 2 个狼人、5 个平民。增加平民，让大家能体验白天投票。
        String[] roles = {"狼人", "狼人", "平民", "平民", "平民", "平民", "平民"};
        boolean[] alive = {true, true, true, true, true, true, true};
        Scanner input = new Scanner(System.in);
        boolean night = true; // true 是夜晚，false 是白天。
        System.out.println("欢迎来到狼人杀！输入 -1 可以退出。");
        while (true) {
            int wolves = 0;
            int villagers = 0;
            System.out.println("存活玩家（编号从 0 开始）：");
            for (int i = 0; i < roles.length; i++) {
                if (alive[i]) {
                    System.out.println(i + "号：" + roles[i]);
                    if (roles[i].equals("狼人")) {
                        wolves++;
                    } else {
                        villagers++;
                    }
                }
            }
            if (wolves == 0) {
                System.out.println("平民胜利！");
                break;
            }
            if (wolves >= villagers) {
                System.out.println("狼人胜利！");
                break;
            }
            if (night) {
                System.out.println("夜晚：狼人要淘汰谁？");
            } else {
                System.out.println("白天：大家要投票淘汰谁？");
            }
            // 先检查输入，防止输入文字导致程序出错。
            if (!input.hasNext()) break;
            if (!input.hasNextInt()) {
                System.out.println("请输入整数编号。");
                input.next();
                continue;
            }
            int target = input.nextInt();
            if (target == -1) break;
            if (target < 0 || target >= roles.length) {
                System.out.println("没有这个编号，请重新输入。");
                continue;
            }
            if (!alive[target]) {
                System.out.println("这个玩家已经出局了。");
                continue;
            }
            if (night && roles[target].equals("狼人")) {
                System.out.println("狼人不能淘汰同伴。");
                continue;
            }
            alive[target] = false;
            System.out.println(target + "号玩家出局。");
            night = !night; // 夜晚变白天，白天变夜晚。
        }
        System.out.println("游戏结束。");
    }
}
```

## Car.java：汽车模板：保存一辆车的信息

### 这个文件负责什么

brand 保存品牌，pricePerDay 保存整数日租金，rented 保存是否租出。构造方法用来给新车填写初始资料。

### 程序怎样执行

new Car("丰田", 100) → 构造方法填写字段 → rented=false。调用 rent 后变 true；调用 returnCar 后变 false。

### 完整源码

```java
// Car 类就像一张汽车信息卡。
public class Car {
    private String brand;
    private int pricePerDay;
    private boolean rented;

    public Car(String brand, int pricePerDay) {
        this.brand = brand;
        this.pricePerDay = pricePerDay;
        rented = false;
    }
    public String getBrand() { return brand; }
    public int getPricePerDay() { return pricePerDay; }
    public boolean isRented() { return rented; }
    public void rent() { rented = true; }
    public void returnCar() { rented = false; }
}
```

## RentalApp.java：主程序：把类串成租车流程

### 这个文件负责什么

car 是唯一一辆车；order 初始为 null，代表还没有订单。主菜单反复出现，选择 1 租车、2 还车、0 退出。

## ShapeManager.java：图形收纳盒：数组和多态

### 这个文件负责什么

shapes 有10个位置，初始每格为 null。add 找到第一个空格放对象；remove 找到指定对象后清空该格；display 遍历非空格并求和。

### 程序怎样执行

依次添加矩形、圆、三角形到下标0、1、2 → 显示时求20+12.566…+6 → 移除圆使下标1为null → 再次显示只求20+6。

### 完整源码

```java
public class ShapeManager {
    private Shape[] shapes = new Shape[10]; // 最多放 10 个图形。
    public void add(Shape shape) {
        if (shape == null) return;
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] == null) {
                shapes[i] = shape;
                return;
            }
        }
        System.out.println("已经放满了。");
    }
    public void remove(Shape shape) {
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] == shape) {
                shapes[i] = null;
                return;
            }
        }
    }
    public void display() {
        double total = 0;
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] != null) {
                Shape shape = shapes[i];
                System.out.println(shape.getColor() + "图形，面积：" + shape.getArea());
                total = total + shape.getArea();
            }
        }
        System.out.println("总面积：" + total);
    }
}
```

### 这个文件负责什么

### 程序怎样执行

### 完整源码

import java.util.ArrayList;
import java.util.Iterator;
import java.util.LinkedHashMap;
import java.util.Map;

public class Agricultural {
    // 用“分”存金额，例如 5020 分就是 50.20 元，避免小数计算误差。
    public static int sum(ArrayList<Integer> money) {
        int total = 0;
        Iterator<Integer> it = money.iterator();
        while (it.hasNext()) {
            total = total + it.next();
        }
        return total;
    }
    public static void main(String[] args) {
        ArrayList<Integer> rice = new ArrayList<Integer>();
        rice.add(5020); rice.add(2958); rice.add(2032);
        ArrayList<Integer> wheat = new ArrayList<Integer>();
        wheat.add(1312); wheat.add(6666); wheat.add(1012);
        ArrayList<Integer> corn = new ArrayList<Integer>();
        corn.add(3032); corn.add(9532); corn.add(1493);
        Map<String, Integer> totals = new LinkedHashMap<String, Integer>();
        totals.put("水稻", sum(rice));
        totals.put("小麦", sum(wheat));
        totals.put("玉米", sum(corn));
        int all = 0;
        for (String name : totals.keySet()) {
            int money = totals.get(name);
            System.out.printf("%s部门：%.2f元%n", name, money / 100.0);
            all = all + money;
        }
        System.out.printf("本月合计：%.2f元%n", all / 100.0);
    }
}

# expt08 代码详细讲解

先阅读本目录《实验说明.md》完成一次运行，再阅读下面每个文件。源码中的行号仅用于定位，不要复制行号到 IDEA。

## Panda.java：三个售货员共用十件库存

### 这个文件负责什么

三个 Panda 对象对应三个线程。remaining 和 LOCK 是 static，所有线程共享；检查和扣减库存必须使用同一把锁。main 用 join 等待三个线程结束后汇报。

### 程序怎样执行

拿锁 → 判断库存是否为0 → 用11-remaining得到编号 → 库存减1 → 打印 → 退出同步块释放锁 → 下一轮竞争。第一件编号1，最后一件编号10；线程顺序不确定。

### 完整源码

```java
// 三个平台同时售卖，同一份库存只有 10 件。
public class Panda extends Thread {
    private static int remaining = 10;
    private static final Object LOCK = new Object();
    public Panda(String name) { super(name); }
    @Override
    public void run() {
        while (true) {
            // 同一时刻，只允许一个线程检查和修改库存。
            synchronized (LOCK) {
                if (remaining == 0) break;
                int number = 11 - remaining;
                remaining--;
                System.out.println(getName() + "卖出第" + number + "件，剩余" + remaining + "件");
            }
        }
    }
    public static void main(String[] args) throws InterruptedException {
        Panda a = new Panda("官网");
        Panda b = new Panda("直营店");
        Panda c = new Panda("授权店");
        a.start(); b.start(); c.start(); // 启动三个线程。
        a.join(); b.join(); c.join(); // 等它们全部结束。
        System.out.println("售卖结束，剩余" + remaining + "件");
    }
}
```
