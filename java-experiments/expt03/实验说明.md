# 实验3：一辆汽车的租借与归还（高中生入门版）

## 先做什么

先运行看到结果，再读代码。一次只学本实验的几个知识点，不要求一次理解所有英文。建议按实验 1～8 的顺序学习；第 4、5、8 个实验可以分两次学习。

## 打开与运行（每个实验都一样）

1. 安装 JDK 8 或更新版本，以及 IntelliJ IDEA。
2. 完整解压，在 IDEA 选择 File → Open，打开本实验 expt03 文件夹。
3. 如果提示没有 JDK，在 File → Project Structure → Project SDK 选择本机 JDK。语言级别选 8。
4. 打开 src/RentalApp.java，点 main 左边的绿色三角，选择 Run。
5. 需要输入时，先点击下方 Run 窗口，再输入内容并按回车。

## 这次只学这些知识

1. 类和对象：Car 是汽车模板，new Car(...) 按模板创建一辆汽车。

2. 属性：brand、pricePerDay、rented 分别记录品牌、日租金和是否已租。

3. 方法：rent()、returnCar() 是汽车可以执行的动作。

4. private：不让其他类随意修改属性，先通过公开方法读写。

5. Rental：保存一次租车记录，总价等于日租金乘以天数。

## 跟着做

1. 先阅读 Car.java，再阅读 Rental.java，最后阅读 RentalApp.java。

2. 运行 RentalApp，输入 1 选择租车，再输入 3 表示租 3 天。

3. 检查总租金是否为 300 元。

4. 再次输入 1，检查是否提示汽车已出租。

5. 输入 2 归还汽车，再输入 1 和 1，检查是否能重新租车。

6. 输入 0 退出；也可以测试天数 0，观察提示。

## 运行后应该看到

租 3 天为 300 元，不能重复出租，还车后可再次租车。

## 自己动手的小练习

把每天租金改成 80 元，计算租 5 天需要多少钱，再运行核对。

## 和原实验的区别

入门版只保留一辆车、品牌、日租金和状态，暂不讲车型、颜色、构造重载和多车管理；不保存历史订单。

## 选学：命令行

在本实验目录执行。已有 out 文件夹时跳过第一行：

```sh
mkdir out
javac -encoding UTF-8 -d out src/*.java
java -cp out RentalApp
```

## 常见问题

找不到 JDK：先确认安装的是 JDK，不是只有 JRE。中文乱码：把项目编码设为 UTF-8。运行按钮不出现：右键 src，选择 Mark Directory as → Sources Root。更改代码后要重新运行，旧输出不会自动改变。
