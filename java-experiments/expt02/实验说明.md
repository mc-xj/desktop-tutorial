# expt02：狼人杀游戏

## 目标与文件

完成“狼人杀游戏”实验。代码兼容 Java 8，无第三方依赖。

- `src/WerewolfGame.java`

## 代码知识

`String[]` 保存身份，`boolean[]` 保存存活状态，同一个下标对应同一玩家。`for` 统计人数，`while` 驱动回合，`if/else` 判断胜负。`&&`、`||` 组合校验条件；先检查下标再访问数组可以避免越界。`Scanner` 获取输入，`Integer.parseInt` 转换整数，捕获 NumberFormatException 后允许重输。winner 方法返回 0/1/2 表示未结束/平民胜/狼人胜。

## 实验步骤

1. 查看 ROLES 与 alive 的对应关系，玩家编号从 0 开始。
2. 阅读 winner 方法，确认平民胜的条件是狼人为 0，狼人胜的条件是狼人数量大于等于平民。
3. 运行 WerewolfGame，输入 0，观察不能攻击同伴，再输入 99 和 abc 检查输入校验。
4. 输入 2，观察一名平民死亡后双方均为 2 人，狼人立即胜利。
5. 如需练习白天投票，临时在自己的练习副本中增加两名平民；原始 2 狼 3 民配置按题目胜负规则首夜即结束。

## IDEA 打开与运行

解压后在 IDEA 选择 File → Open，选择本目录 `expt02`。在 File → Project Structure → Project 设置已安装的 JDK（8 或更新版本），Language level 选择 8。`src` 已配置为 Sources Root；如未识别，右键 src → Mark Directory as → Sources Root。打开 `WerewolfGame.java`，点击 main 左侧绿色三角运行。也可选择预置的 `WerewolfGame` 运行配置。项目不包含机器专属 JDK 路径，需要首次选择本机 SDK。

## 命令行运行

在本实验目录执行（Windows、macOS、Linux 均可；先保证 JDK 在 PATH 中）：

```sh
mkdir out
javac -encoding UTF-8 -source 8 -target 8 -d out src/*.java
java -cp out WerewolfGame
```

`out` 已存在时跳过 mkdir；JDK 9+ 也可用 `javac --release 8 -encoding UTF-8 -d out src/*.java`。Windows 如通配符未展开，可逐一列出 src 中的 Java 文件。

## 预期结果与验收

输入 2 后输出玩家 2 已被杀死、狼人胜利、游戏结束。

## 与原文的差异及限制

统一采用正文要求的 >= 胜负条件；原文夜间用 >、白天用 >=，存在不一致。保留题目角色配置，因此正常对局首夜结束，白天流程需增加平民才能体验。
