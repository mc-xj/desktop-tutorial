# 实验三：汽车租赁系统（车辆数组版）

使用Car[]保存3辆车，以Rental[]保存对应租赁记录，两个数组同一下标对应同一辆车。类、private、getter/setter、构造重载、Scanner等课堂内容保留。

1. IDEA打开expt03，设置JDK，运行Test.main。
2. 输入1、1、3：租1号车3天，总价300元。
3. 输入1、2、2：租2号车2天，总价160元，不覆盖1号车订单。
4. 输入2、1：只归还1号车，2号仍已租。
5. 子步骤输入0返回菜单，主菜单输入0退出。

详细解释与完整源代码见《代码详细讲解.md》，Word版为《实验三_代码详细解释.docx》。旧实验报告未修改。

命令行：先创建out目录，再执行javac -encoding UTF-8 -d out src/*.java，然后java -cp out Test。
