## Shape.java：图形父类

### 这个文件负责什么

抽取所有图形共用的颜色、尺寸校验、面积接口和文字描述。

### 程序怎样执行

子类先用 super 初始化颜色。打印图形时调用 toString，其中的 getArea 会执行实际子类的公式。

### 完整源码

```java
public abstract class Shape {
    private String color;

    protected Shape(String color) {
        setColor(color);
    }

    public String getColor() { return color; }
    public void setColor(String color) { this.color = color; }

    protected static void requirePositive(double size) {
        if (!Double.isFinite(size) || size <= 0) {
            throw new IllegalArgumentException("尺寸必须是有限正数");
        }
    }

    public abstract double getArea();

    @Override
    public String toString() {
        return String.format("%s，颜色：%s，面积：%.2f",
                getClass().getSimpleName(), getColor(), getArea());
    }
}
```

## Triangle.java：三角形

### 这个文件负责什么

保存三条边，校验合法性，再用海伦公式算面积。

### 程序怎样执行

以 3、4、5 为例，半周长为 6，再求 √(6×3×2×1)，面积为 6。

### 完整源码

```java
public class Triangle extends Shape {
    private double a;
    private double b;
    private double c;

    public Triangle(double a, double b, double c) {
        super("绿色");
        setSides(a, b, c);
    }

    public double getA() { return a; }
    public double getB() { return b; }
    public double getC() { return c; }

    public void setSides(double a, double b, double c) {
        requirePositive(a);
        requirePositive(b);
        requirePositive(c);
        // 三边必须同时满足三角形不等式。
        if (a + b <= c || a + c <= b || b + c <= a) {
            throw new IllegalArgumentException("任意两边之和必须大于第三边");
        }
        this.a = a;
        this.b = b;
        this.c = c;
    }

    @Override
    public double getArea() {
        double p = (a + b + c) / 2;
        return Math.sqrt(p * (p - a) * (p - b) * (p - c));
    }
}
```

## ShapeManager.java：图形管理器

### 这个文件负责什么

以 Shape 数组管理不同图形，添加、删除、显示并汇总面积。

### 程序怎样执行

添加时找到空格，移除时用 == 找到指定对象，显示时跳过空格并累加面积。

### 完整源码

```java
import java.util.HashMap;
import java.util.Map;

public class ShapeManager {
    private final Shape[] shapes = new Shape[10]; // 最多放 10 个图形。
    private final String[] names = new String[shapes.length];
    private final Map<Class<? extends Shape>, Integer> counts = new HashMap<>();

    public void add(Shape shape) {
        if (shape == null) return;
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] == null) {
                Class<? extends Shape> type = shape.getClass();
                int number = counts.getOrDefault(type, 0) + 1;
                counts.put(type, number);
                String name = type.getSimpleName();
                if (type == Circle.class) {
                    name = "圆形";
                } else if (type == Rectangle.class) {
                    name = "矩形";
                } else if (type == Triangle.class) {
                    name = "三角形";
                }
                names[i] = name + " " + number;
                shapes[i] = shape;
                return;
            }
        }
        System.out.println("已经放满了。");
    }
    public void remove(Shape shape) {
        if (shape == null) return;
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] == shape) {
                shapes[i] = null;
                names[i] = null;
                return;
            }
        }
    }
    public void display() {
        double total = 0;
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] != null) {
                Shape shape = shapes[i];
                System.out.println(names[i] + "｜" + shape);
                total = total + shape.getArea();
            }
        }
        System.out.printf("总面积：%.2f%n", total);
    }
}
```

## ShapeApp.java：运行入口

### 这个文件负责什么

演示向上转型、字符串比较、图形增删和非法三角形。

### 程序怎样执行

添加四个图形后总面积为 88.83，移除第一个圆和三角形后为 70.27。比较颜色时，== 得到 false，equals 得到 true。尝试修改成 1、2、3 后，原三角形面积仍为 6。

### 完整源码

```java
public class ShapeApp {
    public static void main(String[] args) {
        Shape rectangle = new Rectangle(4, 5); // 向上转型
        Shape circle = new Circle(2);
        Triangle triangle = new Triangle(3, 4, 5);
        ShapeManager manager = new ShapeManager();
        manager.add(rectangle);
        manager.add(circle);
        manager.add(triangle);
        manager.add(new Circle(4));
        System.out.println("添加后：");
        manager.display();

        // 两段内容相同的文字可以来自不同对象。
        String color = new String("红色");
        System.out.println("比较颜色引用：" + (rectangle.getColor() == color));
        System.out.println("比较颜色内容：" + rectangle.getColor().equals(color));

        manager.remove(circle);
        manager.remove(triangle);
        System.out.println("移除第一个圆形和三角形后：");
        manager.display();

        try {
            triangle.setSides(1, 2, 3);
        } catch (IllegalArgumentException e) {
            System.out.println("三角形校验失败：" + e.getMessage());
            System.out.println("原三角形面积仍为：" + triangle.getArea());
        }
    }
}
```
