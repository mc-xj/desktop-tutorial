## HelloWorld.java：第一段会输出文字的程序

### 这个文件负责什么

入口先输出问候，再创建Student对象并调用方法，最后用for循环依次输出数组元素。

### 程序怎样执行

main → 输出问候 → new Student创建学生 → introduce输出姓名年龄 → 创建scores数组 → for依次输出85、90、95 → main结束。

### 完整源码

```java
// 类名 HelloWorld 必须和文件名相同。
public class HelloWorld {
    // 程序从 main 方法开始运行，先记住这个固定写法。
    public static void main(String[] args) {
        // println 表示输出一行文字。
        System.out.println("Hello, World!");
        System.out.println("我是高中生，我正在学习 Java！");

        // 类是模板，对象是根据模板创建的具体事物。
        Student student = new Student("小明", 16);
        student.introduce();

        // 数组把多个同类型的数据放在一起，下标从 0 开始。
        int[] scores = {85, 90, 95};
        // 从第 0 格开始，每次向后移动一格，直到数组末尾。
        for (int i = 0; i < scores.length; i++) {
            System.out.println("第" + (i + 1) + "次成绩：" + scores[i]);
        }
    }
}
```

## Student.java：学生类：属性、构造方法和自我介绍

### 这个文件负责什么

name 保存姓名，age 保存年龄。private 限制其他类直接访问这些属性，introduce 提供公开的自我介绍动作。

### 程序怎样执行

new Student("小明",16) 调用构造方法 → this.name 保存小明 → this.age 保存16 → student.introduce() 输出介绍。

### 完整源码

```java
// Student 是学生的模板，记录姓名和年龄。
public class Student {
    private String name;
    private int age;

    // 创建学生对象时，把传入的姓名和年龄保存起来。
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 方法描述对象能够做的事：介绍自己。
    public void introduce() {
        System.out.println("我是" + name + "，今年" + age + "岁。");
    }
}
```

### 容易弄错的地方

this.name 是当前对象的字段，右边 name 是传入参数；构造方法与类同名，没有 void。Student 不需要 main，由 HelloWorld 创建并调用。
