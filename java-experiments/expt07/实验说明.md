# expt07：智慧农业月度实际预算统计

## 目标与文件

完成“智慧农业月度实际预算统计”实验。代码兼容 Java 8，无第三方依赖。

- `src/Agricultural.java`

## 代码知识

List<E> 表示同类型元素序列，泛型在编译阶段检查类型。Iterator 的 hasNext/next 用于遍历。Map<K,V> 保存部门与金额的映射，entrySet 同时取得键和值。LinkedHashMap 保留插入顺序，让输出稳定。BigDecimal 使用字符串构造避免二进制浮点误差；对象不可变，因此加法要用 total = total.add(...) 保存新结果。

## 实验步骤

1. 核对三个部门的原始报销记录，理解每个 List 对应一个部门。
2. 阅读 amounts 方法，用字符串构造 BigDecimal 金额。
3. 单步执行 sum，观察迭代器与累加过程。
4. 运行 Agricultural，核对部门金额和总金额。
5. 在练习副本中追加一条 10.00 元记录，重新运行，确认所属部门和总额均增加 10.00。

## IDEA 打开与运行

解压后在 IDEA 选择 File → Open，选择本目录 `expt07`。在 File → Project Structure → Project 设置已安装的 JDK（8 或更新版本），Language level 选择 8。`src` 已配置为 Sources Root；如未识别，右键 src → Mark Directory as → Sources Root。打开 `Agricultural.java`，点击 main 左侧绿色三角运行。也可选择预置的 `Agricultural` 运行配置。项目不包含机器专属 JDK 路径，需要首次选择本机 SDK。

## 命令行运行

在本实验目录执行（Windows、macOS、Linux 均可；先保证 JDK 在 PATH 中）：

```sh
mkdir out
javac -encoding UTF-8 -source 8 -target 8 -d out src/*.java
java -cp out Agricultural
```

`out` 已存在时跳过 mkdir；JDK 9+ 也可用 `javac --release 8 -encoding UTF-8 -d out src/*.java`。Windows 如通配符未展开，可逐一列出 src 中的 Java 文件。

## 与原文的差异及限制

按标题统一使用“本月”，修正原文混用季度/年度。将 Double 改为 BigDecimal 保证金额精确；本实验统计实际报销额，不包含计划预算和预算差额。
