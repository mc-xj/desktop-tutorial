# Java 实验：高中生入门版

8 个小实验，按“先运行 → 看注释 → 改一点 → 再运行”的顺序学习。每个项目独立，无需 Maven、数据库或其他依赖。

## 从哪里开始

1. 完整解压压缩包。
2. 在 IntelliJ IDEA 选择 File → Open，先打开 expt01 文件夹。
3. 在 Project Structure 中选择本机 JDK（8 或更新版本）。
4. 阅读对应的《实验说明.md》，点击 main 左侧绿色三角运行。

不要一次打开所有项目，也不必先背语法。遇到不懂的地方，先读中文注释，再按说明做一个小修改。

| 实验 | 内容 | 入口类 |
| --- | --- | --- |
| 1 | Java 环境与第一行输出 | HelloWorld |
| 2 | 狼人杀小游戏 | WerewolfGame |
| 3 | 汽车租赁系统（课堂板书版） | Test |
| 4 | 图形面积小助手 | ShapeApp |
| 5 | 美食烹饪大赛 | CookingApp |
| 6 | 早上 9 点打卡 | AttendanceApp |
| 7 | 三个农业部门的费用统计 | Agricultural |
| 8 | 三个窗口卖十件挂件 | Panda |

前两个实验学习输出、变量、数组、循环和判断；实验三到五学习对象、继承和接口；实验六到八接触异常、集合和线程。后半部分难度较高，可以先完成运行和小练习，再逐步理解。

## 版本说明

本版为教学简化版，不宣称逐项覆盖原文全部考核要求。汽车只保留一辆、三角形使用底和高、打卡改用 LocalTime；各实验说明列出了具体差异。如老师要求严格复现实验清单，应以老师要求为准。

每个项目附中文注释和小练习；Word 汇总见《实验知识与步骤汇总.docx》，实际检查结果见《验证结果.md》。IDEA 配置已提供，首次打开仍需选择本机 JDK。
