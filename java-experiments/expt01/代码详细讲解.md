# expt01 代码详细讲解

先阅读本目录《实验说明.md》完成一次运行，再阅读下面每个文件。源码中的行号仅用于定位，不要复制行号到 IDEA。

## HelloWorld.java：第一段会输出文字的程序

### 这个文件负责什么

入口直接执行两个 println，没有输入、判断或循环。

### 程序怎样执行

main → 输出英文问候 → 输出中文自我介绍 → main 结束。

### 完整源码

```java
// 类名 HelloWorld 必须和文件名相同。
public class HelloWorld {
    // 程序从 main 方法开始运行，先记住这个固定写法。
    public static void main(String[] args) {
        // println 表示输出一行文字。
        System.out.println("Hello, World!");
        System.out.println("我是高中生，我正在学习 Java！");
    }
}
```

### 逐行解释

| 行号 | 代码 | 解释 |
| --- | --- | --- |
| 1 | `// 类名 HelloWorld 必须和文件名相同。` | 中文注释：类名 HelloWorld 必须和文件名相同。。这行不参与运行。 |
| 2 | `public class HelloWorld {` | 定义这个文件中的公共类。 |
| 3 | `// 程序从 main 方法开始运行，先记住这个固定写法。` | 中文注释：程序从 main 方法开始运行，先记住这个固定写法。。这行不参与运行。 |
| 4 | `public static void main(String[] args) {` | 程序入口。public 允许 JVM 访问，static 无需先建对象，void 不返回值，args 接收启动参数。 |
| 5 | `// println 表示输出一行文字。` | 中文注释：println 表示输出一行文字。。这行不参与运行。 |
| 6 | `System.out.println("Hello, World!");` | 向运行窗口输出结果。println 会换行；+ 把文字与变量值拼接成一条消息。 |
| 7 | `System.out.println("我是高中生，我正在学习 Java！");` | 向运行窗口输出结果。println 会换行；+ 把文字与变量值拼接成一条消息。 |
| 8 | `}` | 结束当前代码块；对应前面某个左大括号。 |
| 9 | `}` | 结束当前代码块；对应前面某个左大括号。 |

### 容易弄错的地方

把引号内的文字改成自己的姓名不会改变程序结构；不要改 main 的大小写。
