# Java 代码详细解释：高中生入门版

本讲解对应当前 expt01～expt08 源码。建议打开源文件，边看代码边读解释；行号与本版本一致。代码没有修改，本材料只增加解释。

## 先认识几个符号

- `;`：通常表示一条语句结束。括号 `()` 放方法的参数或判断条件，大括号 `{}` 划出一块代码的范围。
- `=`：把右边的值保存到左边；`==`：判断是否相等。`!` 表示取反，`&&` 要求两边都成立，`||` 要求至少一边成立。
- `int`：整数；`double`：小数；`boolean`：true/false；`String`：文字。`String` 是类，不是基本数据类型。
- `public`：允许其他类访问；`private`：只允许本类直接访问；`static`：属于类；`final`：赋值后不能重新指向别的值或对象。
- `new`：创建对象。变量保存对象的引用，可以理解为找到对象的“地址线索”，并不等于复制整个对象。
- `void`：方法不返回结果；`return 值`：把结果交给调用者；单独的 `return`：立即结束这个方法。
- `main`：JVM 启动普通控制台程序时寻找的入口。`String[] args` 接收运行参数，并不是键盘输入；键盘输入在本项目中通过 Scanner 读取。
- `break`：结束所在的最近一层循环；`continue`：结束本轮循环，准备下一轮；两者都不是“关闭所有程序”的通用命令。
- `//` 后是注释，给人看，不会被执行。IDEA 行号、中文讲解和代码中的标点不能混在一起粘贴进源码。

## 先弄清三个不同动作

1. 编写：把代码保存到 .java 文件。
2. 编译：javac 检查语法和类型并生成 .class 文件。
3. 运行：java/JVM 执行字节码，从 main 开始。某个辅助类没有 main 很正常，它会被入口类使用。

## HelloWorld.java：第一段会输出文字的程序

### 这个文件负责什么

入口先输出问候，再创建Student对象并调用方法，最后用for循环依次输出数组元素。

### 程序怎样执行

main → 输出问候 → new Student创建学生 → introduce输出姓名年龄 → 创建scores数组 → for依次输出85、90、95 → main结束。

### 完整源码

```java

public class HelloWorld {
    // 程序从 main 方法开始运行，先记住这个固定写法。
    public static void main(String[] args) {
        // println 表示输出一行文字。
        System.out.println("Hello, World!");
        System.out.println("我是高中生，我正在学习 Java！");

        // 类是模板，对象是根据模板创建的具体事物。
        Student student = new Student("小明", 16);
        student.introduce();

        // 数组把多个同类型的数据放在一起，下标从 0 开始。
        int[] scores = {85, 90, 95};
        // 从第 0 格开始，每次向后移动一格，直到数组末尾。
        for (int i = 0; i < scores.length; i++) {
            System.out.println("第" + (i + 1) + "次成绩：" + scores[i]);
        }
    }
}
```

## WerewolfGame.java：用数组模拟回合游戏

### 这个文件负责什么

roles[i] 是第 i 号玩家的身份，alive[i] 是同一玩家是否存活。两组数组必须一一对应。night 决定当前是夜间攻击还是白天投票。

### 程序怎样执行

初始 2 狼 5 民。输入 2：平民变 4，进入白天；输入 0：狼人变 1，进入夜晚；输入 3：平民变 3；输入 1：狼人变 0，下一轮统计后宣布平民胜。每轮重新统计，不沿用旧人数。

### 完整源码

```java
import java.util.Scanner;

// 这是公开身份的练习小游戏，用来学习数组、循环和判断。
public class WerewolfGame {
    public static void main(String[] args) {
        // 2 个狼人、5 个平民。增加平民，让大家能体验白天投票。
        String[] roles = {"狼人", "狼人", "平民", "平民", "平民", "平民", "平民"};
        boolean[] alive = {true, true, true, true, true, true, true};
        Scanner input = new Scanner(System.in);
        boolean night = true; // true 是夜晚，false 是白天。
        System.out.println("欢迎来到狼人杀！输入 -1 可以退出。");
        while (true) {
            int wolves = 0;
            int villagers = 0;
            System.out.println("存活玩家（编号从 0 开始）：");
            for (int i = 0; i < roles.length; i++) {
                if (alive[i]) {
                    System.out.println(i + "号：" + roles[i]);
                    if (roles[i].equals("狼人")) {
                        wolves++;
                    } else {
                        villagers++;
                    }
                }
            }
            if (wolves == 0) {
                System.out.println("平民胜利！");
                break;
            }
            if (wolves >= villagers) {
                System.out.println("狼人胜利！");
                break;
            }
            if (night) {
                System.out.println("夜晚：狼人要淘汰谁？");
            } else {
                System.out.println("白天：大家要投票淘汰谁？");
            }
            // 先检查输入，防止输入文字导致程序出错。
            if (!input.hasNext()) break;
            if (!input.hasNextInt()) {
                System.out.println("请输入整数编号。");
                input.next();
                continue;
            }
            int target = input.nextInt();
            if (target == -1) break;
            if (target < 0 || target >= roles.length) {
                System.out.println("没有这个编号，请重新输入。");
                continue;
            }
            if (!alive[target]) {
                System.out.println("这个玩家已经出局了。");
                continue;
            }
            if (night && roles[target].equals("狼人")) {
                System.out.println("狼人不能淘汰同伴。");
                continue;
            }
            alive[target] = false;
            System.out.println(target + "号玩家出局。");
            night = !night; // 夜晚变白天，白天变夜晚。
        }
        System.out.println("游戏结束。");
    }
}
```

# 实验三：数组保存车辆版——代码解释

## 1. 本次结构

Car.java保存单辆车的属性、构造方法、getter/setter和租还状态；Rental.java保存一笔租赁的车与天数，并计算租金；Test.java使用Car[]保存3辆车，用Rental[]保存对应订单，负责输入与操作。运行入口为Test.main。Car和Rental的代码保持上一版写法。

## 2. 为什么使用Car[]

`Car[] cars = new Car[3];`创建长度为3的汽车引用数组。此时只有3个空格，每格默认为null，并不等于已经创建3辆车。所以还要分别为cars[0]、cars[1]、cars[2]赋值为new Car(...)。

| 用户看到的编号 | 数组下标 | 汽车 | 日租金 |
| --- | --- | --- | --- |
| 1 | 0 | 丰田 卡罗拉 白色 | 100元 |
| 2 | 1 | 本田 思域 黑色 | 80元 |
| 3 | 2 | 福特 福克斯 银色 | 90元 |

第一辆先使用无参构造，再用setter填写；后两辆使用有参构造。这样同时练习两种创建对象的方式。private字段不能由Test直接读写，需要使用getter/setter。

## 3. 怎样遍历显示

`for (int i = 0; i < cars.length; i++)`依次令i为0、1、2。`Car car = cars[i]`把这一格的汽车引用交给局部变量car，后面通过getter显示信息。这不是复制汽车，更不是创建新车。

`i + 1`只用于显示给用户的编号；真正读取数组时仍使用i。判断car.isRented()，为true显示“已租”，为false显示“可租”。

## 4. 两个数组怎样对应

`Rental[] orders = new Rental[cars.length]`创建同样长度的订单数组，初始各格都是null。固定使用同一个下标关联两组数据：cars[1]是2号车，orders[1]只能保存2号车的订单。

- 未出租：cars[i].isRented()为false，orders[i]为null。
- 出租后：cars[i].isRented()为true，orders[i]指向一笔订单。
- 还车后：恢复false，并把orders[i]重新设为null。

每辆车各有一个订单位置，所以租出1号车后，还能继续租出2号车，不会覆盖1号订单。同一辆车只允许一笔进行中的订单，不保存历史。

## 5. Scanner与readInt

readInt是自定义的静态方法，用来重复利用整数读取代码。hasNext检查是否还有输入（交互时可等待用户输入）；hasNextInt检查下一个内容能否读成整数；nextInt真正取出整数。若输入abc，next()丢弃它，再要求重新输入。

readInt在输入流结束时返回0：主菜单把0作为退出，选车和填天数时把0作为取消。输入流结束后，下一轮主菜单同样读到0，因此程序可以正常结束。readInt并不限制菜单和天数范围，范围由main中对应判断检查。

## 6. 按编号选车

用户输入number后，先检查1到cars.length的范围，然后才计算`int index = number - 1`。例如输入3，index=2，选中cars[2]。

不能在检查前访问cars[number-1]，否则输入99就可能越界。0会直接返回菜单，不会访问-1下标。

## 7. 租车的完整顺序

1. 主菜单输入1，表示租车。
2. 输入车辆编号，例如2，计算index=1。
3. 取cars[1]，检查是否已经出租，已租就拒绝。
4. 输入天数，例如3，校验1到365。
5. `orders[1] = new Rental(car, 3)`创建2号车订单。
6. `orders[1].rentCar()`改变同一辆本田车的状态。
7. `orders[1].getTotalPrice()`返回80×3=240，输出总租金。

构造Rental只是建立记录，rentCar才真正标记已租。汽车和订单通过对象引用关联。总价动态计算，不需要总价setter；正式收费系统还需要保存成交单价，本例不涉及。

## 8. 还车的完整顺序

主菜单输入2，再输入车辆编号。若orders[index]为null，提示没有需要归还的订单。否则先调用returnCar把对应车辆改为可租，再清空这一格订单引用。其他车辆与订单不变。

不要只写orders[index]=null，这不会自动把汽车状态改回false；也不要把整个orders数组重新创建，那会丢失其他车辆正在进行的订单。

```java
// Rental 表示一笔租车记录，关联汽车和租赁天数。
public class Rental {
    private Car car;
    private int rentalDays;

    // 构造方法重载：只提供汽车时，默认租1天。
    public Rental(Car car) {
        this(car, 1);
    }

    // 提供汽车和天数时，按指定天数创建记录。
    public Rental(Car car, int rentalDays) {
        setCar(car);
        setRentalDays(rentalDays);
    }

    public Car getCar() { return car; }
    public void setCar(Car car) {
        if (car == null) {
            throw new IllegalArgumentException("汽车不能为空");
        }
        this.car = car;
    }
    public int getRentalDays() { return rentalDays; }
    public void setRentalDays(int rentalDays) {
        if (rentalDays < 1 || rentalDays > 365) {
            throw new IllegalArgumentException("租赁天数应为1到365");
        }
        this.rentalDays = rentalDays;
    }

    // 总租金由日租金和天数决定，直接计算，不单独设置。
    public int getTotalPrice() {
        return car.getRentPrice() * rentalDays;
    }

    // 创建记录和真正租车分开，便于看清状态变化。
    public void rentCar() { car.rent(); }
    public void returnCar() { car.returnCar(); }
}
```

## ShapeManager.java：图形收纳盒：数组和多态

### 这个文件负责什么

shapes 有10个位置，初始每格为 null。add 找到第一个空格放对象；remove 找到指定对象后清空该格；display 遍历非空格并求和。

### 程序怎样执行

### 完整源码

```java
public class ShapeManager {
    private Shape[] shapes = new Shape[10]; // 最多放 10 个图形。
    public void add(Shape shape) {
        if (shape == null) return;
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] == null) {
                shapes[i] = shape;
                return;
            }
        }
        System.out.println("已经放满了。");
    }
    public void remove(Shape shape) {
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] == shape) {
                shapes[i] = null;
                return;
            }
        }
    }
    public void display() {
        double total = 0;
        for (int i = 0; i < shapes.length; i++) {
            if (shapes[i] != null) {
                Shape shape = shapes[i];
                System.out.println(shape.getColor() + "图形，面积：" + shape.getArea());
                total = total + shape.getArea();
            }
        }
        System.out.println("总面积：" + total);
    }
}
```

## AttendanceApp.java：按一天内的时刻判断迟到

### 这个文件负责什么

### 程序怎样执行

无参数 → 当前北京时间；参数08:59:59 → 成功；09:00:00 → 成功；09:00:01 → throw → 跳过成功输出 → catch显示迟到提示；abc → parse失败 → 另一个catch提示格式错误。

### 完整源码

```java
import java.time.LocalTime;
import java.time.ZoneId;
import java.time.format.DateTimeParseException;

public class AttendanceApp {
    public static void main(String[] args) {
        LocalTime deadline = LocalTime.of(9, 0, 0); // 早上 9 点。
        LocalTime now = LocalTime.now(ZoneId.of("Asia/Shanghai"));
        try {
            // 不填参数就使用当前北京时间；填参数可以练习不同情况。
            if (args.length > 0) now = LocalTime.parse(args[0]);
            System.out.println("打卡时间：" + now);
            if (now.isAfter(deadline)) {
                throw new MyException("超过早上 9 点，打卡失败！");
            }
            System.out.println("打卡成功！");
        } catch (MyException e) {
            System.out.println(e.getMessage());
        } catch (DateTimeParseException e) {
            System.out.println("时间格式错误，请填写类似 08:59:59 的时间。");
        }
    }
}
```

```java
import java.util.Iterator;
import java.util.LinkedHashMap;
import java.util.Map;

public class Agricultural {
    // 用“分”存金额，例如 5020 分就是 50.20 元，避免小数计算误差。
    public static int sum(ArrayList<Integer> money) {
        int total = 0;
        Iterator<Integer> it = money.iterator();
        while (it.hasNext()) {
            total = total + it.next();
        }
        return total;
    }
```

## Panda.java：三个售货员共用十件库存

### 这个文件负责什么

三个 Panda 对象对应三个线程。remaining 和 LOCK 是 static，所有线程共享；检查和扣减库存必须使用同一把锁。main 用 join 等待三个线程结束后汇报。

### 程序怎样执行

拿锁 → 判断库存是否为0 → 用11-remaining得到编号 → 库存减1 → 打印 → 退出同步块释放锁 → 下一轮竞争。第一件编号1，最后一件编号10；线程顺序不确定。

### 完整源码

```java
// 三个平台同时售卖，同一份库存只有 10 件。
public class Panda extends Thread {
    private static int remaining = 10;
    private static final Object LOCK = new Object();
    public Panda(String name) { super(name); }
    @Override
    public void run() {
        while (true) {
            // 同一时刻，只允许一个线程检查和修改库存。
            synchronized (LOCK) {
                if (remaining == 0) break;
                int number = 11 - remaining;
                remaining--;
                System.out.println(getName() + "卖出第" + number + "件，剩余" + remaining + "件");
            }
        }
    }
    public static void main(String[] args) throws InterruptedException {
        Panda a = new Panda("官网");
        Panda b = new Panda("直营店");
        Panda c = new Panda("授权店");
        a.start(); b.start(); c.start(); // 启动三个线程。
        a.join(); b.join(); c.join(); // 等它们全部结束。
        System.out.println("售卖结束，剩余" + remaining + "件");
    }
}
```
