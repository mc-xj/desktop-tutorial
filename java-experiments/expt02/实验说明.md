# 实验2：狼人杀小游戏（高中生入门版）

## 先做什么

先运行看到结果，再读代码。一次只学本实验的几个知识点，不要求一次理解所有英文。建议按实验 1～8 的顺序学习；第 4、5、8 个实验可以分两次学习。

## 打开与运行（每个实验都一样）

1. 安装 JDK 8 或更新版本，以及 IntelliJ IDEA。
2. 完整解压，在 IDEA 选择 File → Open，打开本实验 expt02 文件夹。
3. 如果提示没有 JDK，在 File → Project Structure → Project SDK 选择本机 JDK。语言级别选 8。
4. 打开 src/WerewolfGame.java，点 main 左边的绿色三角，选择 Run。
5. 需要输入时，先点击下方 Run 窗口，再输入内容并按回车。

## 这次只学这些知识

1. 数组：一排有编号的小格子。roles 存身份，alive 存是否存活；编号从 0 开始。

2. boolean：只有 true 和 false 两种值，可以表示“活着”和“出局”。

3. if：满足条件才执行；while：反复执行；for：逐个查看玩家。

4. continue：跳过这次操作重新输入；break：结束循环。

5. wolves++：狼人数加 1；night = !night：切换白天和夜晚。

## 跟着做

1. 先阅读 roles 数组，找出狼人和所有平民的编号。

2. 运行程序，输入 2，让平民 2 在夜晚出局。

3. 白天输入 0，把狼人 0 投票出局。

4. 夜晚输入 3，白天输入 1，观察平民胜利。

5. 重新运行，依次输入 2、3、4，观察狼人胜利。

6. 试试输入 99、文字或已死亡的编号；输入 -1 退出。

## 运行后应该看到

输入 2、0、3、1 时平民胜；输入 2、3、4 时狼人胜。

## 自己动手的小练习

把“玩家出局”的提示文字换成自己喜欢的说法。

## 和原实验的区别

为了体验完整回合，初始角色改为 2 狼 5 民。公开身份只是教学演示，并非完整狼人杀规则。

## 选学：命令行

在本实验目录执行。已有 out 文件夹时跳过第一行：

```sh
mkdir out
javac -encoding UTF-8 -d out src/*.java
java -cp out WerewolfGame
```

## 常见问题

找不到 JDK：先确认安装的是 JDK，不是只有 JRE。中文乱码：把项目编码设为 UTF-8。运行按钮不出现：右键 src，选择 Mark Directory as → Sources Root。更改代码后要重新运行，旧输出不会自动改变。
