# expt08：模拟冰墩墩挂件预售

## 目标与文件

完成“模拟冰墩墩挂件预售”实验。代码兼容 Java 8，无第三方依赖。

- `src/Panda.java`

## 代码知识

Thread 子类通过重写 run 定义任务，start 创建并启动线程，直接调用 run 不会开启并发。static 库存由所有实例共享，static final Object 锁也必须共享。synchronized 将检查和扣减组成临界区，防止多个线程同时出售最后一件。sleep 进入限时等待且不会主动释放已有锁，所以放在锁外。join 使主线程等待售卖线程结束。线程可经历 NEW、RUNNABLE、BLOCKED、TIMED_WAITING、TERMINATED 等状态；进程拥有独立运行资源，线程共享同一进程内存。

## 实验步骤

1. 查看 remaining、sold、LOCK，理解为什么必须是共享变量/锁。
2. 阅读 run 中的 synchronized 块，确认检查库存与修改库存都在锁内。
3. 运行 Panda，观察三个销售渠道的输出；具体先后顺序由线程调度决定。
4. 核对售出编号 1～10 各出现一次，没有负库存，总共恰好 10 条售卖记录。
5. 重复运行多次，确认最终始终已售 10 个、剩余 0 个，理解结果一致但渠道分配不固定。

## IDEA 打开与运行

解压后在 IDEA 选择 File → Open，选择本目录 `expt08`。在 File → Project Structure → Project 设置已安装的 JDK（8 或更新版本），Language level 选择 8。`src` 已配置为 Sources Root；如未识别，右键 src → Mark Directory as → Sources Root。打开 `Panda.java`，点击 main 左侧绿色三角运行。也可选择预置的 `Panda` 运行配置。项目不包含机器专属 JDK 路径，需要首次选择本机 SDK。

## 命令行运行

在本实验目录执行（Windows、macOS、Linux 均可；先保证 JDK 在 PATH 中）：

```sh
mkdir out
javac -encoding UTF-8 -source 8 -target 8 -d out src/*.java
java -cp out Panda
```

`out` 已存在时跳过 mkdir；JDK 9+ 也可用 `javac --release 8 -encoding UTF-8 -d out src/*.java`。Windows 如通配符未展开，可逐一列出 src 中的 Java 文件。

## 预期结果与验收

售出 10 件且无重复编号，最后输出：冰墩墩卖完了，已售10个，剩余0个。

## 与原文的差异及限制

修正原文在锁外读取共享库存的方式；使用专用锁对象，增加 join 和统一售罄汇总。休眠缩短为 20ms 便于实验，不保证每个渠道恰好卖出固定数量。
